# 혼자 여행 맞춤 추천

## 사용자 결정

- 추천 루트의 `출발·도착 맞춤`에서 시작 위치 바로 위에 작은 `혼자 여행` 체크박스를 둔다. 클릭할 때마다 체크·해제된다.
- 체크하면 관광 동선은 유지하되 혼자 이용하기 어렵다는 근거가 있는 장소를 제외한다. 식사는 고깃집·회식형 장소를 빼고, 1인 메뉴가 확인됐거나 메뉴·방문 형태상 혼밥이 무난해 보이는 식당과 식사 메뉴가 확인된 카페에서 고른다.
- 체크를 해제하면 기존 추천 규칙으로 돌아간다. 테마별 추천 코스는 이번 선택의 범위가 아니다.

## 근거와 제한

- 기존 `solo-evidence.json`이 반영된 `public/places.json`의 `soloVerdict`를 우선 사용한다. `not_possible`·`takeout_only`는 제외한다. 단품·후기만 있는 후보와 일부 단품 추정 후보는 실제 1인 주문을 확정하지 않고 방문 전 확인을 표시한다.
- 식사 메뉴가 확인된 카페는 송자르트와 브릭레인만 식사 후보에 넣고 60분 체류를 잡는다. 식사 메뉴 제공 시각은 당일 확인이 필요하다.

## 완료 조건

- 실제 체크박스가 시작 위치 위에 보이고 체크·해제 상태가 왕복 전환된다.
- 체크 상태의 식사 후보와 코스 생성에 혼자 이용하기 어렵다고 분류된 식당이 섞이지 않는다.
- 카페 식사는 메뉴 확인 장소만 나오고 60분 체류가 적용된다.
- 혼자 여행 식사 필터와 기존 루트·Worker 검증을 실행하고, 실패하는 기존 검증은 원인과 범위를 기록한다. PR과 배포 상태를 각각 확인한다.
