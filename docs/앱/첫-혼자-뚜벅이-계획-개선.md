# 첫 혼자 뚜벅이 여행 계획 개선

## 사용자가 확정한 흐름

1. 맞춤 추천과 날짜별 테마 루트를 각각 한 화면에서 비교한다.
2. 여러 루트에서 원하는 장소를 골라 계획표에 담는다. 테마 장소는 담을 때마다 방문 시각을 고르며, 확인된 운영시간에 맞는 시각만 허용한다. 운영시간이 없거나 미확인인 장소는 시각을 확정해 담지 않는다.
3. 직접 만든 계획표에서 출발지를 등록 장소 선택 또는 주소 검색으로 지정한다. 방문 순서의 이동시간과 경로를 확인한다. 시간이 부족하거나 경로가 미확인이어도 경고를 보여주고 저장을 허용한다.
4. 처음 이용하는 사람에게 화면 안의 짧은 단계 안내를 보여준다.

## 구현과 판정 범위

- 맞춤 결과 비교는 방문 수, 도보 거리, 버스 구간, 예상 도착 시각, 장소 순서를 보여준다. 테마 비교는 선택 날짜의 저장 자료를 사용하고, 확인하지 않은 방문·종료 시각은 확정값으로 표시하지 않는다.
- 테마 장소별 담기는 방문 시작 시각과 예상 체류를 운영시간·휴무·브레이크타임·마감 판정에 대조한다. 날짜별 실제 임시휴무와 현장 입장 가능 여부는 별도로 확인해야 한다.
- 계획표는 출발지부터 첫 장소, 장소 사이, 저장된 도착지가 있으면 마지막 장소부터 도착지까지 확인한다. 한 도보 구간 1.6km·30분, 하루 도보 8km를 기준으로 경고한다. 버스 후보는 배차와 실제 운행을 확정하지 않는다. 좌표나 경로 자료가 없으면 미확인으로 표시한다.
- 지도 번호는 방문 순서를 뜻하며 실제 이동 경로선은 아니다. 개인 계획은 기존 기기 저장 방식을 유지한다.

## 검증 상태

- `node scripts/build.mjs`, `node --check public/app.js`, `node --check dist/client/app.js`, `node verification/verify-plan-audit.cjs`, `node scripts/verify-worker.mjs`, `git diff --check`를 통과했다.
- 실제 화면 조작은 내장 브라우저 연결 시간 초과로 검증하지 못했다. 배포 후 실제 화면 확인과 방문일 운영·버스 배차 확인은 별도 항목이다.
