# 2026년 휴일 테마 루트 점검

확인일: 2026-10-08(한국 시간). 휴일은 토·일요일과 2026년 대한민국 공휴일로 분류했다. 공휴일 날짜는 [한국천문연구원 월력요항 발표](https://www.kasi.re.kr/kor/post/newsMaterial/32031)를 바탕으로 정리하고, 나중에 지정된 노동절·제헌절은 [인사혁신처 발표](https://www.mpm.go.kr/mpm/comm/newsPress/newsPressRelease/?boardId=bbs_0000000000000029&cntId=4250&mode=view)를 반영했다. 임시공휴일 추가 여부는 이후 점검 대상이다.

## 확인 범위와 미확인 사항

- 저장한 8개 버전은 **닫는 장소의 대체 장소 운영표와 보행 경로**를 확인한 결과다. 전체 방문지의 특정 날짜 실제 영업이나 임시휴무까지 확정하지 않았다. 계획표의 기본 시각은 장소별 30~45분 체류와 저장 보행시간을 바탕으로 제안한다. 개점·마감 시각과 식사 시각은 계획표에서 사용자가 확인하고 수정해야 한다.
- 토요일의 다른 다섯 경주 테마와 공휴일이 평일에 있는 경우에도 추가 휴무·단축 운영이 생길 수 있다. 1월 1일, 설·추석의 박물관·전시시설 휴관 등은 대체 장소와 연결 경로까지 확인되지 않아 별도 버전으로 저장하지 않았다. 앱에서는 해당 휴일에 검증된 별도 버전이 없음을 알린다.
- 목포 일부 카페와 강릉·경주의 식당/상점은 공식 운영표가 없거나 지도 자료가 서로 다르다. 장소 정보의 요일별 문구를 루트 전체 검증으로 취급하지 않는다. 시장 개별 점포, 공연·분수, 버스 배차, 실제 문 위치와 현장 통제도 방문일 확인이 필요하다.
- GitHub의 주간·월간 장소 점검은 공개 출처 문구 변경을 이슈에 모으고 해당 테마 제목과 휴일 파일 재검토 지침을 붙인다. 승인한 장소 자료 변경은 빌드 시 요일별 변경 루트 생성기가 반영한다. 휴일 대체 파일은 별도 근거와 길선을 다시 확인한 뒤 갱신한다.
