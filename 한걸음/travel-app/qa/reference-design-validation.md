# 2026-10-04 참고 이미지 기반 디자인 재조정

## 사용자 피드백과 반영

- 홈 목포가 원래 그림보다 실사 역사관으로 바뀐 점을 지적했다. `mokpo-card.webp`를 다시 연결하고 실제 사진이라는 잘못된 대체텍스트·표지 출처 문구도 수정했다. 장소 상세의 실제 사진은 유지했다.
- 최신 참고 화면의 큰 손글씨 제목, 아래쪽에 모인 해안·다리·풀꽃과 거북이, 이미지 위에 겹친 크림색 카드, 지역 안내 말풍선, 작은 테마 그림·꽃, 세이지 팁 영역을 분석해 공통 스타일에 적용했다.
- 사용자가 지정한 Cafe24 Dongdong을 직접 제공한다. 홈 제목·감성 섹션·지역명·말풍선·팁 제목만 적용하고 장소명·설명·검색·버튼·탭·지도는 Pretendard를 유지한다.
- [4화면 비교](reference-four-screens.jpg), [자산·생성 프롬프트](../dist/assets/diary/reference-README.md), [글꼴 출처](../dist/assets/fonts/README.md).

## 기능 보존 근거

- [수정 전 파일](reference-app-before.js)과 [변경 비교](reference-app.diff): `app.js`는 대표 그림·대체텍스트·출처 및 장식 말풍선만 변경했다. 기존 이벤트 연결은 동일하다.
- 장소 데이터, 추천 엔진, 지도 설정, 장소별 이미지 카탈로그의 SHA-256이 같다. [검사 결과](reference-preservation.json), [수정 전 기준](reference-preservation-baseline.json).
- 기존 4개 메뉴, 현재 목포만 제공하는 범위, 6개 테마, 상세 정보 구조, 실제 지도 타일·좌표·분류·경로 의미를 유지한다. 참고 이미지에 보이는 신규 찜·알림·마이·다른 도시를 추가하지 않았다.
- 서비스 워커는 필수 시각 자산과 캐시 버전만 갱신했다. JS 문법 및 필수 캐시 자산 존재 검사를 통과했다.

## 브라우저 확인

- Codex 인앱 브라우저로 홈→지역→장소→운영시간→지도 위치→지도/목록, 홈→지역→처음 가는 목포 추천 입력, 계획표·저장 메뉴를 직접 조작했다.
- 360px 홈·지역, 390px 홈·지역·장소·지도·목록·추천 입력·계획표·저장, 768px 홈, 1280px 홈·지역에서 가로 넘침이 없었다. [검사값](reference-browser-report.json).
- 실제 지도 하단에 장소 130곳·지도 핀 130곳이 유지됐다. 특정 장소로 확대된 지도에서 현재 뷰포트 안에 붙은 DOM 마커 수는 전체 장소 수와 다르다.
- 정보성 장소명 Pretendard 27px, 버튼 13–14px, 감성 홈 제목 Cafe24 Dongdong 42px, 감성 섹션 28px, 팁 제목 25px을 확인했다. 폰트 자체의 글자 높이에 맞춰 감성 텍스트만 크기를 조정했다.
- 이미지 누락 검사에 잡힌 계획표의 `turtle-memo.png`는 화면 아래 `loading=lazy`, `complete=false`인 미요청 이미지다. 파일·오프라인 캐시에 존재하며 네트워크 오류로 판정하지 않았다. 보이는 이미지와 콘솔에는 오류가 없었다.
- 넓은 화면에서 배경이 확대·잘리며 글자 뒤에 바다가 올라오는 문제를 발견해 배경 비율을 조정하고 다시 캡처했다.
- 현장 여행 가독성·선호도는 측정하지 않았다. 나머지 128개 장소의 전용 그림·사진은 여전히 미등록이며 기존 유형 이미지로 표시한다. 이번에는 추천 엔진을 수정하지 않아 실제 경로 계산 전수 검사를 반복하지 않았다.
