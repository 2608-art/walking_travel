# 실제 도보 시간 재검사 후 추천 결과 소실 수정

검증일: 2026-10-04 한국 시간. 기준 여행일도 2026-10-04이며 당일 영업 보증이 아니다.

## 재현과 원인

- 사용자 확인 조건: 목포역→목포역, 10:00→자정, 필수 장소 없음. 기존 배포 v16에서 맞춤 결과 없음, 같은 날짜 `처음 가는 목포`는 9곳 성공.
- 동일 지점 금지나 되돌아감 금지가 원인은 아니다. 기존 엔진에 가까운 출발·도착(직선 200m 미만) 주변 탐색이 있다. 도로가 겹치지 않는 완전한 순환을 보장하는 규칙은 아니다.
- 추정 도보 시간으로 12곳을 배치한 뒤 실제 경로를 확인하면, 노적봉→역사관1관이 2분→9분으로 늘어난다. 이후 목포대중음악의전당 방문이 17:10→17:20으로 밀려 45분 체류가 18시 폐관을 넘는다. `confirmRoute`가 전체 후보를 버리고 재배치하지 않았다.
- 사용자는 같은 조건이었다고 확인하고, `순서 조정 우선 → 필요할 때 선택 장소 축소`를 선택했다. 새로운 순환 거리 기준이나 도보 상한 완화는 적용하지 않았다.

## 변경

- 실제 조회 구간 캐시로 기존 방문지를 이동·구간 반전해 재배치하고 다시 실제 API로 검증한다. 실패하면 필수 장소를 보존하며 선택 방문지를 줄인다.
- 맞춤과 테마의 최초 경로 검증에 동일하게 적용한다. 고정 식사·버스 연결을 임의 재배치하지 않는다. 출발·도착, 시간, 도보 상한과 기존 영업 판정은 유지한다.
- 재배치 이유와 제외한 선택 장소를 결과 화면에 표시한다. 같은 방문 순서가 되는 중복 후보는 제거한다.
- 탐색은 단계별 최대 24개 방문지 집합, 단계당 실제 확인 8회·후보당 총 24회로 제한한다. 전역 최적해·모든 가능한 코스 발견을 보장하지 않는다.

## 한계와 배포

- 모든 날짜·주소·필수 장소 조합을 검사한 것은 아니다. 실제 출입구·현장 보행·임시휴무·버스 배차는 별도 확인이 필요하다.
- 사용자가 전날 보았던 정확한 방문 순서·과거 API 응답은 확보하지 못했다. 현재 실패 원인을 재현한 것이며 최초 발생 시점을 단정하지 않는다.
