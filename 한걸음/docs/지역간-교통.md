# 목포에서 인접 지역으로 이어지는 대중교통

조사일: 2026-10-01. 지역을 넘는 **이동 구간**만 기록한다. 각 지역의 관광지·지역 내 이동은 해당 지역 파일에 둔다. 자가용·렌터카·택시는 제외한다. 시간표는 특정 여행일의 실제 운행·잔여 좌석을 보증하지 않는다.

## 목포 ↔ 나주: 철도

[SR 열차 시간표 게시판](https://etk.srail.kr/cms/archive.do?pageId=TK0402050000)의 **2026-09-01 기준 호남선 시간표**에서 양방향 정차역과 시각을 대조했다. 두 역 사이 **26~28분**인 열차가 있어 '기차 30분 내외' 조건을 충족한다. 아래는 모두 시간표에서 운행요일이 `매일`로 표시된 예시다. 열차 편명·예매 가능 여부·임시 변경은 여행일에 다시 확인한다.

| 방향 | 열차 | 출발 → 도착 | 소요 |
| --- | --- | --- | --- |
| 목포역 → 나주역 | 410 | 09:05 → 09:32 | 27분 |
| 목포역 → 나주역 | 412 | 09:39 → 10:06 | 27분 |
| 목포역 → 나주역 | 434 | 18:03 → 18:30 | 27분 |
| 나주역 → 목포역 | 431 | 18:47 → 19:13 | 26분 |
| 나주역 → 목포역 | 623 | 19:15 → 19:41 | 26분 |
| 나주역 → 목포역 | 435 | 20:43 → 21:09 | 26분 |

**연결 예시, 아직 코스 확정 아님:** 목포 09:05 → 나주 09:32 뒤 나주역 정류장 순환2 09:50 → 금성관 10:00. 귀환은 금성관 순환1 17:03 → 나주역 17:49 뒤 나주 18:47 → 목포 19:13. 역 승강장↔버스 정류장 도보, 각 장소의 실제 운영시간, 버스 정시성, 당일 예매 가능 여부는 미검증이다. 이 예시는 시간표를 결합한 **후보**일 뿐 여행 가능 판정이 아니다. [나주 지역 교통](지역/나주/교통.md)에 버스 출처·정류장 방향을 기록한다.

## 목포 ↔ 무안: 200번 시내버스

[목포시 2026-09-01 공영버스 운행현황](https://m.mokpo.go.kr/www/life_welfare/traffic/city/operation_status), [평일](https://m.mokpo.go.kr/contents/28779/weekday_260901.pdf)·[주말](https://m.mokpo.go.kr/contents/28779/weekend_260901.pdf) 시간표, [목포 ITS 200번](https://its.mokpo.go.kr/its/bus3.view?route_id=324000027) 정류장 목록을 대조했다.

| 방향 | 승차 → 하차 | ITS 순서와 정류장 ID |
| --- | --- | --- |
| 목포 → 무안 | 목포역 `100101019` [34.7911588, 126.3860022](https://www.openstreetmap.org/?mlat=34.7911588&mlon=126.3860022#map=18/34.7911588/126.3860022) → 무안군청 `120000057` [34.9904036, 126.4805637](https://www.openstreetmap.org/?mlat=34.9904036&mlon=126.4805637#map=18/34.9904036/126.4805637) | 7 → 57 |
| 무안 → 목포 | 무안군청 `180000082` [34.9918734, 126.4810988](https://www.openstreetmap.org/?mlat=34.9918734&mlon=126.4810988#map=18/34.9918734/126.4810988) → 목포역 `101503043` [34.7918386, 126.385924](https://www.openstreetmap.org/?mlat=34.7918386&mlon=126.385924#map=18/34.7918386/126.385924) | 62 → 112 |

공식 시간표상 **기점** 삼학도 출발은 평일·주말 05:00부터 21:10까지 전체 구간, 22:10편은 무안교통까지만 간다. 반대 방향 **기점** 무안 출발은 평일 06:20~22:30, 주말·공휴일 05:50~22:00이다. 목포역·무안군청 정류장의 실제 첫차·막차 시각이 아니다. 무안 관광지 위치·무안군청 정류장에서의 접근·귀가편은 별도 검증 전이다.

## 목포 ↔ 영암 삼호권: 300·300A번 시내버스

[목포 ITS 300번](https://its.mokpo.go.kr/its/bus3.view?route_id=324000117)과 [300A번](https://its.mokpo.go.kr/its/bus3.view?route_id=324000032)의 정류장 순서를 조회했다. 두 노선 모두 삼학도차고지 `324000002`에서 출발해 **영암군 삼호읍을 먼저 순환한 뒤 목포역** `101503043`으로 간다. 따라서 목포역에서 이 버스를 타고 영암으로 바로 간다고 안내하면 방향이 틀린다. 삼학도차고지 접근 또는 다른 목포 쪽 승차 지점부터 다시 설계해야 한다.

| 노선 | 삼학도차고지 → 영암권 → 목포역 정류장 순서 | 영암권 정류장 좌표 예시 |
| --- | --- | --- |
| 300 | 1 → 삼호농협 46 → 구.삼호터미널 48 → 농업박물관 57 → 목포역 73 | 삼호농협 `150000043` [34.745422, 126.468652](https://www.openstreetmap.org/?mlat=34.745422&mlon=126.468652#map=18/34.745422/126.468652), 농업박물관 `130001102` [34.775972, 126.456467](https://www.openstreetmap.org/?mlat=34.775972&mlon=126.456467#map=18/34.775972/126.456467) |
| 300A | 1 → 농업박물관 28 → 구.삼호터미널 37 → 삼호농협 39 → 목포역 74 | 농업박물관 `200000037` [34.774557, 126.45756](https://www.openstreetmap.org/?mlat=34.774557&mlon=126.45756#map=18/34.774557/126.45756), 삼호농협 `150000074` [34.7455823, 126.4685326](https://www.openstreetmap.org/?mlat=34.7455823&mlon=126.4685326#map=18/34.7455823/126.4685326) |

**미검증:** 삼학도차고지까지 접근하는 정확한 동선, 영암 정류장별 승하차 시각·첫차·막차, 300/300A의 영암→목포 실제 승차편, 관광지 입구까지의 도보, 날짜별 운행 변동. 공식 PDF는 기점 중심의 시간표라 정류장별 막차로 해석하지 않는다. 관광지와 영암 내부 교통은 [영암 교통](지역/영암/교통.md)에 분리한다.

### 목포역에서 직접 영암으로 가는 500번도 있음 — 추가 발견

[목포 ITS 500번](https://its.mokpo.go.kr/its/bus3.view?route_id=324000123) 정류장 목록은 **목포역** `100101019` 순서 10 → **목포대 대불캠퍼스** 순서 35 → **독천터미널** `150000058` 순서 55(34.7247185, 126.5693293)로 이어진다. 반대 방향 독천터미널 `339000004` 순서 56(34.7247218, 126.5691698) → 목포역 `101503043` 순서 99다. 즉 목포역 출발 영암권 이동은 300·300A보다 **500번이 직접적인 후보**다. [공식 평일](https://m.mokpo.go.kr/contents/28779/weekday_260901.pdf)·[주말 시간표](https://m.mokpo.go.kr/contents/28779/weekend_260901.pdf) 3쪽에는 삼학도 **기점** 06:10부터 20:30까지의 일반 편과 별도 주석이 붙은 22:00편, 독천터미널 **기점** 06:10부터 21:40까지의 편이 실려 있다. 평일과 주말에 500번 표기 시각은 동일하다. **22:00편의 운행 범위는 표 주석을 현장 자료와 더 대조해야 하므로 코스에 사용하지 않는다.** 목포역·독천터미널 중간 정류장별 첫차·막차 시각도 아직 검증하지 못했다.

ITS에는 [900번](https://its.mokpo.go.kr/its/bus3.view?route_id=324000118)·[900A번](https://its.mokpo.go.kr/its/bus3.view?route_id=324000131)도 영암 삼호권 정류장을 경유하는 노선으로 조회된다. 두 노선은 목포역 정류장을 지나지 않아 목포역 출발 직행편으로 기록하지 않는다. 특히 900A번은 농업박물관 정류장을 경유하므로 향후 관광지별 시간 검증 대상으로 남긴다.

## 범위와 다음 검증

- 위는 **존재·방향·일부 시간표가 검증된 연결편**이다. 무안·영암의 하루 관광 가능 여부까지 검증한 것은 아니다.
- 목포와 인접 지역의 다른 버스·철도·여객선 연결을 모두 조사 완료했다고 보지 않는다. 특히 신안 연결과 추가 무안·영암 노선은 별도 조사 대상이다.
- 여행일과 방문 관광지를 정하면 각 정류장의 마지막 승차시각, 실제 도보 이동, 귀가 열차·배편을 양방향으로 다시 조회한다.
