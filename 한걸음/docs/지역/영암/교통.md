# 영암 삼호권 교통 조사 메모

조사일: 2026-10-01. 목포와 경계를 넘는 300·300A·500번의 정류장 방향과 위치는 [지역 간 교통](../../지역간-교통.md)에 기록했다. 영암군 내 관광지 입구와 지역 내 이동은 아직 검증하지 않았다.

현재 확인된 영암 쪽 후보 정류장은 삼호농협, 구.삼호터미널, 농업박물관, 독천터미널이다. **정류장 명칭만으로 관광지까지 걸어갈 수 있는지, 다음 버스나 목포 귀환편을 탈 수 있는지는 판단하지 않는다.** 나중에 영암 코스를 구성할 때 관광지 실제 주소·입구, 정류장까지 보행, 정류장별 첫차·막차를 이 파일에 기록한다.
