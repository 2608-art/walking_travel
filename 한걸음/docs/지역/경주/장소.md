# 경주 장소 조사

조사 기준일: 2026-10-06 (한국 시간). 사용자 결정에 따라 **경주시 전역**을 다룬다. 지도에 표시하는 관광·식음료 장소와, 출발·도착 위치 검색에만 저장하는 숙소를 구분한다. 장소의 존재·주소, 지도 대표점, 실제 보행 출입구, 운영시간, 특정 날짜 코스 가능성은 서로 다른 확인 단계다. 자료에 있다고 모두 확정 추천에 넣지는 않는다.

## 범위와 표시 규칙

- 관광·식음료·시장·상점은 확인 가능한 위치를 지도핀으로 표시한다. 큰 유적·거리·호수·해안의 한 점은 전체 동선이 아니라 대표점이다. 정확한 출입구와 보행 가능 경로를 확인하기 전에는 시간표상 방문 가능 판정에 사용하지 않는다.
- 숙소는 경주시 관광 자료의 이름·주소·출처만 별도 저장한다. **지도핀, 여행지 목록·카드, 추천 방문지에는 표시하지 않는다.** 사용자가 직접 선택한 숙소를 출발·도착 지점으로 지정할 때에만 주소 검색으로 위치를 확인한다.
- 시내권, 보문관광단지, 불국사, 동해안(감포·문무대왕면·양남), 북부(양동·안강), 서부(건천·산내), 남산권을 구분한다. [경주시 관광 권역 분류](https://www.gyeongju.go.kr/tour/)
- 대표 카드는 사용자가 선택한 **첨성대·동궁과 월지의 누각·연못·황리단길 + 불국사·석굴암**의 상징 일러스트다. 무덤 비주얼을 원치 않아 대릉원 고분은 그림에서 뺐다. 장소 후보의 대릉원은 유지한다. 이 그림은 실제로 한 지점에서 보이는 풍경이나 현장 사진이 아니다.

## 가격·시간·사진의 확인 수준

- 경주시 관광 페이지에 게시된 장소별 운영시간과 요금은 **조회일 게시값**으로 기록한다. 상점·카페의 공식 운영사 또는 현장 가격과 충돌하면 가격 수치를 확정하지 않는다. 교리김밥·아덴·스컹크웍스의 게시 운영정보도 임시휴무·라스트오더까지 보장하지 않는다.
- 경주시 [비단벌레 전동차 예약](https://www.gyeongju.go.kr/reserve/exp_facilities/facility_view.jsp?item_id=E0000006&mem_id=B0000035)은 장소가 아닌 탑승 체험으로 교통 조사에 기록한다. 하루 방문지 수를 채우기 위한 독립 장소로 중복 계산하지 않는다.
- 공식 관광 페이지의 사진은 출처 링크일 뿐 앱 복사 허가를 뜻하지 않는다. 실제 장소 사진은 원본·저작자·이용 조건과 장소 일치를 확인한 것만 연결한다. 나머지는 실사진으로 오해시키지 않도록 별도 표기한다.

## 아직 검증하지 않은 것

- 후보 대부분의 **실제 출입구·매표소·보행 시작점**, 계절별·요일별 운영, 임시휴무, 1인 식사 가능 여부와 대기시간, 현행 메뉴 가격.
- 관광지 간 실경로, 버스 정류장 양방향 위치·편별 시각·막차·숙소로 돌아가는 연결. [교통 조사](교통.md)의 노선 후보를 방문 가능 판정으로 승격하지 않는다.
- 경주시 전역의 음식점·카페·숙소 전수 목록. 현재 자료는 확인된 후보의 시작점이며, 지역 전체의 모든 영업장을 수집했다는 뜻이 아니다.

- [`public/gyeongju-places.json`](../../../../public/gyeongju-places.json)에 경주시 여러 권역의 장소 후보 **176곳**(기존 40곳·신규 136곳)을 저장했다. 음식점 48곳·카페 48곳이다. 좌표는 장소검색 대표 위치로, 실제 출입문과 보행 경로를 보증하지 않는다.
- [`public/gyeongju-lodgings.json`](../../../../public/gyeongju-lodgings.json)에 공식 관광 자료에서 확인한 숙소 10곳의 이름·주소·출처만 따로 저장했다. 지도나 여행지 카드에 표시하지 않고, 출발·도착지를 검색할 때 위치를 확인한다.

장소 상세의 `장소 정보` 링크는 첫 방문 후기 원문으로 연결하고, `평점 출처`와 `운영정보 출처`는 각각 별도로 유지했다. 새로운 장소 38곳은 `researchOnly` 상태로, 교통과 당일 영업 검증 전 자동 코스에서 제외한다. 혼합 평가(빼돌린숯불뒷고기·커피업), 업무 중 방문자의 추천(오베르), 경주 반복 방문·동네 카페 추천을 여행객의 일괄 호평으로 바꾸지 않았다. 산내그로브 주소, 아레나피나·러스틱커피 휴무·마감 등 상충 정보는 화면·근거 자료에 남겼다.

테를지는 현행 상호와 기존 매장의 동일성을 확인하지 못해 보류했고, 필모어커피는 방문기에서 운영 종료를 밝혀 신규로 넣지 않았다. 낙지마실·소옥 등 Google 4.0 미만 후보는 Kakao 4.0 이상을 확인하지 못해 이번 추가에서 보류했다. 이번 조사에서 검증 기준을 충족한 38곳을 모두 통합했으며, 경주시 모든 영업점을 빠짐없이 조사했다는 뜻은 아니다.
