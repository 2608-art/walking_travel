# 경주 카페 혼자 이용 조사

확인: 2026-10-06 (한국 시간). 기존 카페 48곳의 저장된 공개 메뉴·운영·방문 자료를 대조하고, 직접 혼자 방문 원문 6곳을 재확인했습니다. 카페 담당 서브에이전트의 검색 진행 뒤 Codex가 원문 검증과 저장을 이어받았습니다. 미확인 42곳은 혼자 방문 불가 판정이 아닙니다. 전 점포 현재 정책을 전화 확인한 조사는 아닙니다.

## 직접 방문 및 별도 좌석 근거

### 스컹크웍스

- 혼자 떠난 경주 여행에서 스컹크웍스를 직접 방문해 콜드브루와 쑥인절미 쿠키를 주문하고 쉬었다고 기록합니다. 창가 이용만으로 전용 1인석을 추정하지 않습니다. [서따지](https://seoddaji.tistory.com/205) · 게시 2024-12-22 · 방문 미확인 · 확인 2026-10-06

### 엘로우

- 혼자 경주 여행 중 엘로우에 방문해 커피와 크루아상을 주문하고 오래 머문 직접 후기입니다. 추가 주문은 작성자의 선택이며 매장의 최소 주문 조건으로 해석하지 않습니다. [박하씨 (파카씨)](https://psyworld.co.kr/1271) · 게시 2020-10-09 · 방문 미확인 · 확인 2026-10-06

### 소풍가다 경주양남본점

- 혼자 방문하여 트리플 먹물식빵과 리얼 카카오 라떼를 주문한 직접 후기입니다. 2021년의 주문 경험이며 현재 1인 1음료 규정이나 식사 메뉴의 근거는 아닙니다. [슬아](https://s-record.tistory.com/entry/초대형-신상-카페-경주-양남-소풍가다) · 게시 2021-07-20 · 방문 미확인 · 확인 2026-10-06

### 향미사

- 인원을 나 혼자로 명시한 경주 여행기에서 향미사 커피 한 잔을 포장했다고 기록합니다. 매장에 앉아 식사했다는 근거는 아닙니다. [무명의 더쿠](https://theqoo.net/travel/1994428152) · 게시 2021-05-21 · 방문 2021-05-05~08 (본문 여행 기간) · 확인 2026-10-06
- 배우자와 방문한 글의 바 좌석 설명을 좌석 유형 근거로만 사용합니다. 혼자 방문한 직접 후기로 세지 않습니다. [태양과 구름](https://otter93.tistory.com/8) · 게시 2025-02-14 · 방문 미확인 · 확인 2026-10-06

### 오베르

- 혼자 방문했다고 명시하고 아메리카노와 크림치즈 마늘 바게트볼·베이커리 오믈렛을 주문한 직접 후기입니다. 빵 주문을 식사 메뉴나 현행 최소 주문 조건 확인으로 확대하지 않습니다. [겸이네맘](https://wldud0926.tistory.com/entry/경주-충효동-대형-식물원-카페-오베르-다녀온-후기) · 게시 2024-09-06 · 방문 게시 당일 (본문 현장에서 작성) · 확인 2026-10-06

### 오크냅 러스틱커피

- 배우자 없이 혼자 나들이해 오트라떼를 주문하고 창가의 낮은 소파를 이용한 직접 후기입니다. 일반 소파를 전용 1인석으로 판정하지 않습니다. 다른 손님의 브런치 식사는 작성자의 혼자 식사 경험과 구분합니다. [라라see](https://clara727.tistory.com/11) · 게시 2023-11-14 · 방문 미확인 · 확인 2026-10-06

## 판정 기준과 한계

커피·빵을 혼자 주문한 후기는 혼자 카페 방문 근거이며, 혼자 식사한 후기와 구분합니다. 향미사의 포장 경험은 포장 전용 조건이 아닙니다. 향미사의 바 좌석은 별도 2025년 동반 방문 글에서 확인했고, 혼자 방문 후기로 좌석을 추정하지 않았습니다. 오크냅 러스틱커피의 일반 창가 소파는 전용 1인석으로 분류하지 않았습니다. 러스틱·우드페커의 식사 메뉴는 메뉴 근거로만 쓰며 혼자 식사한 직접 후기라고 표현하지 않습니다. 봄갤러리의 가족 방문, 1925감포·바이닐바이브의 동반 방문·태그는 직접 혼자 방문 확정 근거에서 제외합니다.

SNS·지도·인터넷 카페의 접근 제한이나 검색 태그만으로 방문을 확정하지 않습니다. 기존 48곳의 상세 필드·출처·확인 기록은 [조사 JSON](혼자여행-카페-조사.json)에 보존했습니다.
