# 경주 6개 테마별 장소 후보 초안

기존 경주 장소 176곳만 사용해 후보 핀을 만들었습니다. 지도는 선택한 테마의 핀만 표시합니다. 후보는 기준점에서 가까운 순으로 고르되, 각 테마의 권역 밖으로 숫자를 채우지 않았습니다. 테마 사이 중복 장소가 있을 수 있습니다.

> 핀은 직선거리로 후보 권역을 추린 결과이며, 실제 보행 가능 여부·장소 출입구·방문 순서를 확정하지 않습니다. 외곽 테마는 저장된 장소만으로 30곳에 못 미칩니다.
