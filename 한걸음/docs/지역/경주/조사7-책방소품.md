# 경주 조사7 — 책방·소품

조사일: 2026-10-06 (KST). 범위: 경주시 전역에서 탐색하되, 확인된 독립서점과 로컬 소품점은 시내·황리단길·서악동에 집중되어 있다. 기존 경주 40곳에 `books` 분류는 없다. 아래 평점은 **Google 지도 원본 화면을 직접 열어 확인**했으며, 사용자가 어느 지도앱을 기준으로 삼을지 아직 확정 전이므로 앱 추가 확정값이 아니다. 상품 가격과 영업시간은 변동성이 높다. 확인 못 한 값은 추정하지 않는다.

## 우선 통합 후보

### 어서어서책방 — 황리단길 독립서점
- 위치: 경주시 포석로 1083. - 지도 평점: Google **4.2/5, 216건** (원본 지도 화면 확인). 카카오·네이버 수치 미확인.
- 방문 성격: 소설·에세이·인문학 책을 고르고, 구매 책을 약봉투 형태의 종이봉투에 담는 콘셉트. 경주시 관광 자료와 [2026 여행 유튜브](https://www.youtube.com/watch?v=iSphewkKNaU)에서 존재 교차 확인.

- 비용: 서점 입장은 통상 구매 없이 가능하나 명시된 공식 입장 정책 없음. 개별 도서 정가·약봉투 별도 요금 유무 미확인. 가격을 임의로 쓰면 안 됨.
- 사진: 경주시 상세에 실제 매장 사진이 있으나 페이지에서 사진별 공공누리 표시를 확인하지 못함. [경주시 저작권 정책](https://www.gyeongju.go.kr/open_content/ko/page.do?mnu_uid=1070)은 공공누리 표시가 없는 자료는 사전 협의하라고 명시. 매장 사진 무단 재사용 금지. 예시 책방 사진을 쓴다면 **실제 장소 아님** 표시 필요.

## 사진 권리와 표기

- 실제 매장 사진 후보는 경주시 관광·웹진·Google 지도·방문 블로그에 있으나, **각 사진의 재사용 허가가 명시적으로 확인되지 않았다**. 경주시 저작권 정책 자체가 사진별 공공누리 표기를 확인하라고 한다. 추후 운영자 허가나 KOGL 표시가 확인되면 실제 사진으로 교체할 수 있다.
- 확실한 예시 사진: Wikimedia Commons [Bookstore shelves.jpg](https://commons.wikimedia.org/wiki/File:Bookstore_shelves.jpg), Punker1999, CC0 1.0. **경주 장소 사진이 아니라 해외/일반 책방 예시**임을 카드와 이미지 대체 텍스트에 표시해야 한다. 다른 예시로 [Bookstore Interior.jpg](https://commons.wikimedia.org/wiki/File:Bookstore_Interior.jpg), MarkBuckawicki, CC0 1.0도 가능하지만 실제 촬영지는 미국 버몬트다.
- 지도 이용자 사진은 Google 지도에서 보이더라도 재배포 라이선스로 보지 않는다.

## 사용자 화면에 넣기 전 공통 확인

1. 사용자 확정 지도앱의 **4.0 이상 평점**을 각 신규 장소 페이지에서 재확인. 현재 직접 확인된 것은 Google 뿐이다.
2. 각 가게의 운영자 SNS 최근 공지에서 임시 휴무와 명절 운영 확인. 특히 어서어서·디스모먼트는 지도와 시 관광 안내가 충돌한다.
3. 가격이 제시되지 않은 도서·소품은 `품목별 상이 · 현장 확인`으로 표기하고 수치를 만들지 않는다. 과거 가격은 `과거 방문 정보`로만 남긴다.
4. 경주시 전역 탐색은 서악동·읍성·중앙시장·황리단길까지 확대했으나, 동해안·불국사권에서 평점과 현행 운영을 동시에 확인한 독립서점/로컬 소품점은 찾지 못했다.
