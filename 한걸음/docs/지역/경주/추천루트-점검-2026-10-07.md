- 기존 장소는 176곳이다. 추가 조사 136곳은 `researchOnly`로 자동 코스에서 제외된다. 이는 실제 운영·교통 검증 전 제외하는 기존 정책이다. 일괄 해제하지 않았다.

2026-10-06의 혼자 이용·예약 검증은 직접 혼자 식사 후기의 후보 허용, 카페 방문과 식사 구분, 예약 경고 연결 같은 규칙과 화면 검증이었다. 경주 실제 장소와 실제 이동을 이용한 완성 코스 생성 성공을 입증한 검사가 아니었다. 이번 점검에서 다섯 테마의 자동 생성이 모두 막혀 있음을 직접 재현했다.
