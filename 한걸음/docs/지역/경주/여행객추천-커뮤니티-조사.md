## 판정·이미지 원칙

- 경주시 밖 장소는 후보에서 제외한다. 같은 상호의 타지역 지점과 혼동하지 않는다.
- 기존 138곳과 상호·주소로 중복을 대조하고, 새 장소는 Kakao 또는 Google 지도 4.0 이상을 직접 확인해야 한다. 이 문서의 카페 회원 별점·집계 평점은 등재 근거로 사용하지 않았다.
- 여행객이 직접 주문·대기·맛·재방문 의향을 기록한 글을 우선하며, 현지인 추천·회원 후기 재게시·영상 집계·검색 단서를 서로 다른 확인 수준으로 남긴다.
- 블로그·SNS 사진은 열람했다고 앱 재사용 허가가 생기지 않는다. 이 조사에서 개인 사진을 앱에 복사하지 않았다. 신규 앱 사진은 부모 작업에서 이용 조건을 확인한 실제 사진 또는 실제 장소가 아닌 예시 사진을 표시한다.
- 최종 추가·보류·탈락, 현재 지도 점수·평가수·영업·가격 확인은 음식점·카페 담당 결과와 부모 통합 기록에 이어서 남긴다.
