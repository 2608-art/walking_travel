## 기준·범위

기존 음식점 35곳과 중복을 제외했다. 신규는 Kakao 또는 Google 지도 한 곳 4.0 이상이라는 사용자 기준을 적용했다. 아래 별점은 주소가 경주시인지 확인한 Google 원본 지도 장소 화면에서 직접 읽었고, 다이닝코드 별점으로 대체하지 않았다. 시내·보문 북군·배동·안강·충효·시래동 불국사권·천북을 조사했다.

실제 방문 블로그 원문에서 대기·주문·동행·식사사진·여행 맥락을 확인했다. 내돈내산 선언이 없으면 협찬 없다고 단정하지 않았다. 과거 가격은 현행으로 옮기지 않았다. 다이닝코드 운영·가격은 조회 당시 공개 보완 정보이며 가게 확정 공지와 구분한다. 지도와 정보가 다르면 차이를 남겼다. 빼돌린숯불뒷고기의 혼합 평가는 강추천으로 바꾸지 않았다.

확인 후보 13곳. 전체 인터넷의 모든 후보를 소진했다는 의미는 아니다. 접근되지 않는 SNS·인터넷 카페·네이버 원문과 아래 보류 후보를 조사 한계로 남긴다. [구조 데이터](./여행객추천-음식점-추가데이터.json)의 좌표는 Google 장소 URL 전체 PlusCode의 해독 중심점이며 출입구·정류장 검증은 별도다.
