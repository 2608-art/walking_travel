# 경주 여행객 추천 카페 추가 조사

조회: 2026-10-06 (한국 시간). 기존 경주 카페 23곳과 중복을 제외해 조사했다. 지도 원본 평점 4.0 이상을 확인한 후보 25곳이며, 미확인 후보는 아래에 남겼다. 앱 등재·사진 연결·교통 검증 여부는 통합 담당 결과에서 따로 확인한다.

## 조사 기준

- 검색 추천 목록을 출발점으로 삼고, 실제 방문·주문·맛 평가가 있는 블로그 원문을 읽었다. 내돈내산은 작성자의 표기이며 영수증이 없는 글의 실제 결제를 독립적으로 보증하지 않는다. 협찬 여부 미표시와 내돈내산 표기를 구별했다.
- 경주시 안만 포함한다. 동명 카페(특히 용인시 아무카페), 기존 안강 소디스와 현곡 본점을 구별했다.
- 신규 등재 평점은 Kakao 또는 Google 원본 한 곳 4.0 이상이다. 별도집계사이트/블로그의 개인 별점은 기준점수로 쓰지 않았다. 원본 지도 UI는 root 담당이 읽었으며, 카페 담당의 CUA/Aside에는 사용 가능한 브라우저가 없었다.
- 운영·가격은 조회일 지도표시 또는 출처별 게시값이다. 과거 방문 금액과 지금 메뉴값, 상충시간, 작은 평점표본은 명시했다.
- 좌표는 원본 Kakao HTML의 staticmap `srs=wgs84&m=경도,위도` 또는 Google 전체 플러스코드 중심이다. 출입구 핀으로 확정하지 않는다.
