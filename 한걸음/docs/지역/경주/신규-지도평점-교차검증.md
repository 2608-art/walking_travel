## 책방·소품 분야 직접 검증 완료값

[조사7-책방소품](./조사7-책방소품.md) 조사 때 Google 지도 원본 UI에서 직접 확인: 어서어서 4.2/216, 누군가의책방 4.5/19, 제로스페이스 경주 4.8/23, 디스모먼트 4.6/23, 서점 북미 4.9/49. 각 원본 지도 상세 URL과 주소는 해당 문서에 있다. 모두 Google 기준 4.0 이상이며 영업 충돌·가격·이미지 권리는 별도 검증 대상이다.

## 해석

간접값이 4.0 이상인 문화 후보가 최소 4곳 있지만, 이 문서는 추가 후보를 **원본 확인 완료로 격상하지 않는다**. 원본 UI가 다시 이용 가능할 때 각 링크 또는 `https://www.google.com/maps/search/?api=1&query=장소명%20경주`로 접속해 평점·리뷰·주소를 동일 화면에서 기록하면 된다. 전시관은 엑스포대공원·불국사 본체와 다른 별도 유료시설인지 확인한 뒤 중복 핀을 판단해야 한다.
