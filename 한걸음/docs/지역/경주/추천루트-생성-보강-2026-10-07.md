# 경주 추천 루트 생성 보강 — 2026-10-07 (한국 시간)

## 사용자가 확정한 기준

한 코스 **약 10곳을 목표**로 한다. 운영·관람·이동시간 때문에 어려울 때만 줄이며 **5곳은 정말 최소인 생성 기준**이다. 기존 목포의 이동·시간 제약(구간 1.6km·30분, 하루 도보 8km, 최소 4시간, 출발 후 첫 장소 대기 60분 이하, 최대 20:00 종료)은 유지한다.

## 수정과 근거

- 경주 후보 생성 한도를 8곳에서 10곳으로 바꾸고, 유효 후보 중 10곳에 가까운 결과를 먼저 비교한다. 다른 지역의 목표 수는 변경하지 않았다.
- 길목 후보를 찾았다는 이유로 출발·도착 주변 후보 탐색을 중단하던 문제를 수정했다. 실제 경로 확인에서 탈락한 후보의 대체 동선을 찾는다.
- 점심 삽입 뒤 첫 대기가 60분을 넘는 시간표로 정상 코스를 덮어쓰지 않도록 수정했다.
- 한 구간의 API 오류로 다른 구간의 저장된 실제 경로까지 차단하던 문제를 구간별 실패 기록으로 변경했다. 조회 실패한 구간을 실제 경로로 인정하지 않는다.
- 기존 조사에 저장된 13곳의 운영시간을 계산용 필드에 연결했다. 새 후보 중 소향몽·경주향교·제로스페이스·북샵라벤더·미피스토어·하우해브유빈·사가소 7곳은 기존 공개 운영 근거와 등록 장소 사이 양방향 도보 조회를 기록한 뒤 자동 추천 후보로 연결했다. [운영·구간 근거](../../../../scripts/gyeongju-route-readiness.json)는 저장된 10월 6일 조사와 10월 7일 신규 확인을 구분한다. 휴무 미확인을 연중무휴로 확정하지 않는다.
- 로컬 서버의 경주 등록점 누락을 보완하고 기존 공개 경로 API 중계를 연결했다. [미리보기 실행 스크립트](../../../../scripts/start-local-preview.ps1)는 키를 파일에 저장하지 않는다.
