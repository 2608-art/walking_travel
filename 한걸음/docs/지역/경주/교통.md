# 경주 교통 조사

조사 기준일: 2026-10-06 (한국 시간). 범위는 경주시 전역이다. 아래 노선은 **이동 후보**이며, 특정 날짜·시각에 탈 수 있는 확정 코스가 아니다. 일반 버스의 기점 첫차·막차, 관광지 정류장 도착 시각, 반대 방향 귀환편은 구분한다. 자가용·렌터카·자전거는 기본 이동수단에서 제외한다.

## 확인 수준과 최신성

- [경주시 교통정보센터](https://its.gyeongju.go.kr/)는 노선·정류장·실시간 도착·노선별 시간표를 제공한다. 실시간 예측은 여행일의 확정 운행 약속이 아니다.
- 경주시는 **2026-07-15부터** 경주역세권의 50·51·70·700·710·711번 경유 경로를 개편했다. 이전 관광 자료의 정류장 순서·시간을 그대로 코스에 사용하지 않는다. [경주시 2026-07-09 발표](https://gyeongju.go.kr/news/page.do?mnu_uid=1334&parm_bod_uid=324397&step=258)
- [경주시 버스 요금](https://its.gyeongju.go.kr/busCharge.do)은 일반 시내버스 성인 편도 1,500원, 교통카드 50원 할인, 하차 태그 후 30분 이내 1회 무료환승, 동일 노선 환승 불가로 게시돼 있다. 다른 차종·특별 운행의 요금은 개별 확인한다.
- 경주시 [황리단길 관광지도](https://www.gyeongju.go.kr/hwangridan/images/gj_map_kor.pdf)의 710·711·203번 등은 **권역 연결 발견 자료**다. 관광지도 발행 시점과 2026년 7월 개편의 선후관계가 있어 현행 정류장별 경로·시각은 교통정보센터에서 다시 확인해야 한다.

## 남은 검증

1. 2026년 7월 개편 이후의 **각 노선별 양방향 정류장 순서와 ID·좌표**를 교통정보센터에서 확인한다. 같은 이름의 도로 양편 정류장을 구별한다.
2. 대표 여행일을 정해 **승차 정류장 시각 → 하차 정류장 시각 → 관광지 실제 입구 도보 → 마지막 귀환편**을 편별로 연결한다. 기점 출발 시각을 중간 정류장 승차 시각으로 사용하지 않는다.
3. 동해안 100·150·700·1150번, 서부·북부 203·350번의 주말·공휴일 및 단축 편을 대조하고, 공사·축제·행사 우회 공지를 여행일에 다시 확인한다. 2025년 APEC의 임시 110번 등 [지난 행사 한정 운행](https://gyeongju.go.kr/news/page.do?mnu_uid=1336&parm_bod_uid=305656&step=258)은 현행 상시편으로 쓰지 않는다.
4. 경주역 철도 편별 시각, 터미널 시외버스, 관광버스·호출형 서비스·해상 승객 수단은 이번에 현행 시간표와 이용 조건을 확인하지 못했다. 미확인 수단을 ‘없음’으로 단정하지 않는다.

**현재 결론:** 경주시 전역의 여러 권역에 대중교통 연결 후보가 있지만, 특정 날짜의 하루 일정·귀환을 시간표상 가능하다고 판정할 자료는 아직 충분하지 않다. 앱에는 이동 후보와 미확인 사항을 분리해 표시한다.
