## 결과 요약

- 목적지 첫 화면에 왕경·황리단길, 월성·교촌·동부 유적, 성동·중앙시장, 보문, 불국사, 감포·전촌, 문무왕릉 일대, 양남 주상절리 8개 테마가 최신 이름으로 보인다. 테마 카드를 눌러 추천 코스 화면에 진입하는 동작도 확인했다.
- 대표 카드 그림은 첨성대, 연못·누각, 한옥 거리 풍경을 담고 있고 무덤은 없다. 사용자가 선택한 동궁과 월지 누각·연못 방향과 맞아 보이는 명백한 이름·그림 불일치는 없어 수정하지 않았다. 동해안 권역은 대표 그림에 나타나지 않아 전역의 모든 테마를 설명하는 사진으로 쓰이지는 않는다.
- 현재 생성기는 테마 요청마다 최선 결과 하나만 돌려준다 (`generateThemeDay()`의 `return [best.result]`). 2026-10-07 화면에서 왕경·황리단길은 기존 경로 캐시로 코스 1개가 표시됐고, 다른 7개 테마는 ‘방문 5곳 이상을 실제 이동 경로까지 확인한 시작시간이 없습니다’로 표시됐다. 요청된 테마당 약 10개, 최소 5개·최대 15개의 서로 다른 코스 선택지는 현재 구현·검증되지 않았다.
- 앱 경로 API를 새로 조회하면 로컬 `/api/route`가 HTTP 502를 반환했다. 따라서 기존 화면에 나온 왕경 코스와 저장 경로를 새로 받은 API 응답으로 간주하지 않았다. 같은 날 카카오맵 웹에서 테마마다 대표 구간을 직접 열어 경로선을 확인하고 총 거리·시간을 기록했다.
- 카카오맵 안내 자체가 도보시간은 성인 시속 4km 기준이며 실제 구간과 다를 수 있다고 표시한다. 아래 숫자는 링크에 넣은 전체 출발·경유·도착 순서의 지도 합계다. 장소별 개별 구간 시간표, 신호 대기, 실제 출입구·고도·공사 상황을 전부 검증한 수치가 아니다.

## 접근·운영·식사 확인

- 경주역 → 황리단길 카카오 대중교통 길찾기는 열렸지만 검사 중 상태에서 노선 결과가 나타나지 않았다. 도보·대중교통 역 접근과 각 테마 종료 후 역 귀환은 여덟 테마 모두 확정하지 않았다. 경주시 교통 안내의 710·711·10·100·150번은 노선 방향 후보이며, 2026-07 개편 뒤 편별 정류장 통과 시각과 귀환편 자료가 아니다. [교통 조사](교통.md)
- 실제 식사와 휴식 시간까지 화면에서 확인한 일정은 왕경 코스 한 개다. 소향몽을 12:05~13:05 점심으로 넣고, 대릉원·첨성대·월정교·교촌한옥마을·경주향교를 이어 동궁과 월지에 18:25 도착했다. 나머지 7개는 추천 시간표가 생성되지 않았으므로 식사·간식을 넣었다고 표시하지 않는다.
- 새 대표 지도 링크는 주소 좌표를 입력해 카카오맵이 도보 길선을 렌더링했다. 이것은 지도 웹에서 확인한 경로선이며 앱에 복사 가능한 경로 좌표를 받았다는 뜻은 아니다. 앱으로 옮겨 그릴 길선은 별도 허가가 있는 제공자 API나 OSM 경로 좌표를 써야 한다.
- 저장된 OSM 6개 구간은 과거 조회 자료다. 이번 검증에서는 최신 경로로 간주하거나 카카오 응답으로 바꾸어 부르지 않았다.

## 검증 한계와 후속 기준

현재 완료된 테마별 코스 선택지는 1/0/0/0/0/0/0/0개이며, 테마마다 목표 10개(최소 5개·최대 15개)에 도달한 테마는 없다. 지도에서 확인한 대표 전체선은 각 테마 1개뿐이고, 출발역 접근·귀환, 날짜별 버스 시각, 왕경 외 식사·휴식, 전체 stop-to-stop 세부 거리·신호 대기는 미완료다. 카카오맵 도보 총합은 참고값이며 시간 약속이나 보행 안전 보증이 아니다.

대표 링크 8개로 테마의 공간 연결성은 비교할 수 있지만, 현재 라우트 결과를 10개로 부풀릴 근거는 없다. 개별 대안 코스가 5개 이상 성립하는지, 특히 외곽 테마의 버스 시간표와 마지막 귀환편을 확인한 뒤에야 테마별 코스 선택지 수를 확정할 수 있다.

## 2026-10-07 실제 보행·버스·식사 기준으로 재구성

앞의 “현재 저장 경로”와 지도 검증 표는 수정 전 상태의 이력이다. 아래 값은 사용자가 시내 출발, 실제 보행 가능성, 버스 하루 최대 2~3회, 하루 세 끼, 카페 과다 편성 방지를 지시한 뒤 새로 저장한 경로다.

### 공통 기준과 계산 범위

- 경주 시내 숙소권에서 시작하고 돌아오는 일정을 기본으로 했다. 숙소는 별도로 저장된 자료를 그대로 두며 핀이나 지도 표시는 만들지 않았다. 실제 숙소 위치가 정해지지 않아 숙소부터 테마 시작점까지의 접근 거리는 아래 보행거리에서 제외했다.
- 거리·선은 gpx.studio GraphHopper `foot` 프로필로 새로 조회해 경로파일에 저장했다. 지도 선과 GPX에는 **걷는 구간만** 넣었다. 버스 연결을 직선 또는 도보로 그리지 않았고, 탑승 수는 왕복·구간 환승의 실제 승차 횟수 기준이다.
- 걷기 분은 저장된 경로 엔진의 이동 예상만 가리킨다. 장소 관람·식사·대기·숙소 접근 시간을 포함한 완성 시간표는 아니다.
- 하루 식사 항목은 아침·점심·저녁 세 끼로 채웠고, 카페는 오늘 동선에서 테마당 0~1곳이다. 식당 운영시간·메뉴가격은 기존 장소 조사값을 연결했으며 방문일 재확인 대상으로 표시한다.

### 앱·파일 검증

[경주 GeoJSON](../../../../public/gyeongju-routes.geojson)은 테마 후보와 오늘 방문 순서·세 끼·카페 수·버스 구간을 구분한다. [GPX](../../../../public/gyeongju-theme-routes.gpx)는 버스 연결을 포함하지 않도록 보행 구간별 `trkseg`로 분리했다. 화면은 테마 전환 때 이전 지도를 제거하고, 끊긴 선을 버스 이동으로 설명하며, 계획한 버스 승차 수와 시내 식사·운영시간을 함께 보여준다. `node --check public/app.js`와 경주 8테마 데이터 규칙 검사는 통과했다. 대표 좌표와 실제 출입구 사이 최대 접점 차이가 100m를 넘는 보문·감포·문무·양남 장소에는 현장 진입 확인 안내가 필요하다.

### 길선 접점과 출입구 미확인

보행 그래프의 가장 가까운 접점까지 100m를 넘는 장소는 보문 라원 148m, 감포항 154m, 문무대왕릉 229m, 읍천항 105m다. 지도·GPX는 접점에서 시작하거나 끝나며, 이 간격을 임의의 직선으로 보충하지 않았다. 앱 상세에 장소명과 거리, 출입구·사이 길 미확인 안내를 표시한다. 이 값은 대표 핀과 보행망 사이 거리이며 현장 통행 가능성이나 출입 허가를 확인했다는 뜻이 아니다.

세 끼는 기존대로 아침을 시내 출발 전, 저녁을 시내 복귀 후에 두고 점심은 권역 안의 실제 방문 순서에 유지했다. 카페는 하루 최대 한 곳이다. 시내에서 첫 장소까지의 숙소별 접근은 숙소가 정해지지 않아 선에 포함하지 않았고 숙소 핀도 추가하지 않았다. 외곽 버스 승차 횟수·당일 운행·막차·귀환은 앞서 기록한 미확인 상태로 둔다.
