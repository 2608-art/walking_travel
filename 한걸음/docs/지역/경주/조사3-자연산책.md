# 경주 조사3 — 자연·산책

조사일: 2026-10-06 (한국 시간). 담당 범위는 현재 경주 후보의 자연·산책 10곳과 신규 후보이다. 시 관광 자료의 요금·시간은 **조회일 게시값**이다. 길·해변·항구의 대표 지도점은 전체 산책 코스나 안전한 출입구를 뜻하지 않는다. 해안 풍랑, 산불, 시설 보수와 행사 통제는 방문일 확인이 필요하다.
