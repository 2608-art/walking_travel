# 무안 지역 내 교통 조사 메모

조사일: 2026-10-01. 목포↔무안 200번의 승하차 정류장과 기점 시간표는 [지역 간 교통](../../지역간-교통.md)에 기록했다. 무안군청 정류장에서 실제 관광지까지 이동할 수 있는지, 무안 지역 내부의 버스·도보 연결은 아직 검증하지 않았다. 해당 관광지를 정할 때 장소 주소·입구, 정류장별 승하차 시각과 귀환편을 이 파일에 기록한다.
