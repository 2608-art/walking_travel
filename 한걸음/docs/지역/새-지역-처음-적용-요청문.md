# 새 지역 처음 적용 요청문

이 문서는 새 지역을 한걸음 앱에 처음 추가할 때 Codex에 읽혀 줄 **재사용 요청문**이다. Skill은 아니다. 아래 문장의 `[지역명]`과 `[핵심 권역]`을 채우고, 이 파일 경로와 함께 새 작업에 전달한다.

> `한걸음/docs/지역/새-지역-처음-적용-요청문.md`를 읽고 `[지역명]`을 한걸음 앱에 처음 적용해줘. 우선 조사할 권역은 `[핵심 권역]`이야. 문서의 조사·구현·검증·보고 기준을 따라 진행해줘.

## 새 지역 적용 요청

`[지역명]`을 목포·강릉과 비슷한 수준으로 조사해 앱에 추가해줘. 기존 앱의 홈, 지역 소개, 여행지 목록·상세, 방문 안내, 사진·가격·운영시간 표시, 지도, 추천 테마, 맞춤 코스, 직접 짜는 계획표, 혼자 여행 등 **현재 실제로 동작하는 기능**을 확인하고 새 지역에도 연결해줘. 과거 지역의 화면·추천 규칙을 무조건 복사하지 말고, 현재 앱의 공통 기능과 새 지역에 필요한 자료를 구분해 적용해줘.

먼저 프로젝트의 `AGENTS.md`, `한걸음/prd.md`, `한걸음/포트폴리오-작업기록.md`의 **목포 지역 제작 과정 정리**, 목포·강릉의 지역 조사 문서와 현행 앱 데이터를 읽어줘. 기존 지역의 사용자가 확정한 결정과 AI가 임시로 정한 값을 구분해줘. 새 지역에도 적용할지 결정되지 않은 사항은 구현 전에 구체적으로 질문해줘. 특히 다음 항목을 확인해줘.

- 행정구역과 `[핵심 권역]`의 범위, 포함할 외곽, 당일치기 이동 범위
- 새 지역 전용 추천 테마의 이름·구성·개수: 후보를 제안하되 내가 확정하기 전에는 고정하지 않기
- 테마를 제안하기 전에 장소를 지리적 인접성·실제 이동 편의에 따라 권역으로 먼저 묶기. 권역 자체를 도는 테마와 여러 권역을 가로지르는 관심사 테마를 구분해 제안하고, 각 권역의 포함 장소·이동 연결·소요시간·운영시간 근거를 보여준 뒤 확정받기
- 테마별 출발·도착 지점과 맞춤 코스의 기본 출발·도착 지점: 권역별 테마는 실제 동선에 맞추고, 맞춤 기본값은 내가 결정하면 수정 가능하게 하기
- 긴 도보를 허용할 권역과 감당 가능한 실제 보행 거리·휴식 간격
- 지역 카드·소개 그림의 지역 고유 소재와 최종 시안
- 미리보기 표시와 공개 배포 범위

## 조사 범위와 담당

`[핵심 권역]`을 먼저 폭넓게 조사하고 해당 지역의 외곽도 포함해줘. 검증 가능한 장소를 최대한 많이 찾되 앱에는 **지역당 최대 300곳**만 넣어줘. 기존 장소가 있다면 새 장소 발굴과 동시에 누락·중복을 대조해줘. 서브에이전트를 다음처럼 나눠 조사하고, 별도의 검증 담당이 결과를 독립적으로 확인하게 해줘.

1. 시내·역·시장권 음식점
2. 주요 관광권과 외곽 음식점(해변이 없는 지역은 해당 지역의 주요 권역으로 대체)
3. 카페·디저트 전문점
4. 시장 먹거리·포장 간식
5. 자연·산책·전망 장소
6. 문화·전시·역사 장소
7. 체험·탑승·책방·소품점

교통과 코스 조사는 전체 작업을 맡은 에이전트가 통합해 수행하고, 필요하면 별도 조사 담당을 배정해줘. 검증 담당은 상호·지점·주소, 카카오맵 평점과 평가 수, 운영시간·가격, 사진의 피사체와 사용권, 좌표·접근점을 조사 담당과 독립적으로 대조해줘. **검증을 마친 자료만** 앱에 반영해줘.

## 장소 선정과 출처

카카오맵에서 **해당 장소의 평점 4.0 이상을 직접 확인한 곳**을 우선 찾아줘. 특히 음식점·시장 먹거리는 권역별·음식 종류별로 폭넓게 검색해줘. 각 장소의 카카오맵 직접 링크, 조사일, 평점, 평가 수, 정확한 주소를 기록하고 동명 가게나 다른 지점을 혼동하지 마. 일부 검색 결과만 확인했다면 전체를 조사했다고 표현하지 마. 평점이 없거나 보이지 않는 중요한 관광지는 공식 자료와 방문 가능성을 확인해 포함할 수 있지만, 평점 미표시를 4.0 미만으로 간주하지 마.

각 장소의 요일별 운영시간, 정기·임시 휴무, 휴게시간, 마지막 주문, 예약·계절·날씨 제한, 관람료·탑승료 또는 대표 메뉴와 가격을 가능한 만큼 채워줘. 메뉴명·규격·가격을 짝지어 기록하고 변동 가능성이나 자료 충돌도 표시해줘. 내부 전시실처럼 한 시설 안에서 함께 방문하는 곳은 별도 방문지로 세기보다 해당 시설의 설명에 정리해줘. 독립 출입·예약·요금이 있으면 분리 여부를 확인해줘.

예약 정보가 있는 장소는 **예약 필수·예약 권장·필수 여부 미확인**으로 구분하고, 장소 전체에 적용되는지 특정 클래스·투어·체험에만 적용되는지 기록해줘. 예약 방법·링크, 회차와 마감, 근거 출처와 확인 시점을 가능한 만큼 남겨줘. 장소 카드와 상세 화면에는 확인한 예약 상태와 적용 범위를 따로 표시해줘. 사용자가 그 장소를 **내 시간표에 넣으려 할 때** 경고창을 띄워줘. 필수라면 사전 예약 필요, 권장·미확인이라면 방문 전 확인 필요로 문구를 구분해줘. 일반 관람·구매는 자유롭고 특정 체험만 예약 필수라면 **해당 체험만 예약 필수**라고 명확히 알려줘. 경고창에서 취소하거나 안내를 확인한 뒤 계속 넣을 수 있게 하고, 시간표에 넣었다는 사실을 예약 완료로 표현하지 마.


공식 운영기관·관광 자료·점포 공지, 카카오맵과 다른 지도앱, 블로그·인터넷 카페·유튜브·Instagram·X를 목적에 맞게 대조해줘. 최근 자료와 실제 운영 주체의 공지를 우선하고, 출처마다 확인한 항목과 확인 시점을 남겨줘. 실제로 페이지나 게시물 내용을 열어 보지 못했다면 확인했다고 쓰지 마. 운영시간·가격·영업 상태가 상충하거나 없는 항목은 추측하지 말고 **미확인** 또는 **자료 상충**으로 표시해줘.

음식점·카페의 **혼자 여행 적합성**도 장소 조사 단계에서 확인해줘. 1인 메뉴·주문 조건·1인석·포장 전용 여부와 함께 지도 후기, 블로그·인터넷 카페·SNS의 실제 혼자 방문·식사 경험을 찾아 출처와 방문·게시 시점을 기록해줘. **한 사람이 혼자 식사했다는 직접적인 후기 한 건만 확인돼도, 별도 1인 메뉴 표기가 없어도 그 음식점을 `혼자 여행` 식사 후보에 포함해줘.** 이때 `혼자 식사 후기 확인`으로 근거 수준을 표시하고, 모든 메뉴의 1인 주문 가능 여부나 현재 최소 주문 조건까지 확인된 것으로 쓰지 마. **1인석이 확인된 곳은 `1인석 확인`을 별도 항목으로 표시하고 좌석 종류·근거·확인 시점을 남겨줘.** 혼자 식사한 후기만으로 1인석이 있다고 추정하지 말고, 1인석을 찾지 못했을 때도 좌석이 없다고 단정하지 마. 새 지역에서도 이 기준이 추천 루트와 계획표의 `혼자 여행` 선택에 실제 적용되는지 검증해줘.

## 사진·좌표·교통

각 장소와 관련된 이미지도 찾아 카드와 상세 화면에 넣어줘. 실제 장소 사진은 그 장소·지점의 모습인지와 재사용 권한, 저작자, 라이선스, 출처를 확인한 뒤 사용해줘. 확인 가능한 사진이 없어서 주제 예시를 쓰면 **실제 장소나 상품의 사진이 아님**을 목록과 상세 화면에 분명히 표시해줘. 지역 대표 그림은 흔한 풍경만 그리지 말고 그 지역을 알아볼 수 있는 지형·건축·거리·먹거리 등 고유 요소를 반영한 시안을 제안해 내 결정 후 적용해줘.

장소 좌표는 공식 주소와 지도상의 실제 장소·지점을 대조해줘. 매표소·광장·정류장 등의 대표 핀을 쓸 때는 실제 보행 입구와 같은지 구분하고 한계를 표시해줘. 좌표가 확인되지 않은 장소는 목록에 둘 수 있어도 정확한 지도 핀이나 자동 경로에 넣지 마. 역에서 관광지까지와 귀가 구간까지 도보·대중교통의 실제 연결을 확인하고, 노선·정류장·운행일·방향·시간이 검증되지 않은 버스 정보는 만들어내지 마.

## 테마·맞춤 코스와 화면 적용

루트 테마를 만들기 전에 해당 지역의 조사 장소를 **권역 기반 테마 설계**로 먼저 정리해줘. 가까운 장소를 실제 도보·대중교통 연결과 운영시간을 고려해 권역으로 묶고, 권역별 중심 장소·포함 후보·권역 안의 이동 거리와 시간·접근 거점을 표로 보여줘. 그 다음 `강문·초당마을`, `안목 커피거리`, `시장·월화거리`, `역사·문화`처럼 지리적 권역에 기반한 테마와, `카페 투어`처럼 여러 권역을 잇는 관심사 테마를 나눠 제안해줘. 이 예시는 강릉 사례일 뿐 다른 지역에 그대로 고정하지 마. 먼 권역은 실제 이동이 자연스럽지 않으면 한 코스에 억지로 묶지 말고, 테마마다 포함 권역·출발/도착점·장소 후보·예상 방문 수·이동 가능성·운영시간 적합성을 보여준 뒤 내가 구성을 확정하면 루트를 생성해줘.

테마 코스와 출발지·도착지를 직접 고르는 맞춤 코스 모두 **목포에서 검증·사용하는 루트 생성 규칙을 기준으로** 새 지역에 적용해줘. 목포의 현재 구현과 검증 자료를 먼저 읽고, 규칙을 지역별로 임의 완화하거나 단순한 직선거리 추정만으로 실제 이동이 가능한 코스라고 확정하지 마. 지역마다 다른 출발·도착 지점, 테마, 이동 자료만 교체하고 공통 루트 품질 기준은 유지해줘.

| 항목 | 규칙 |
| --- | --- |
| 한 코스의 방문 장소 수 | 한 코스에 보통 약 10곳을 목표로 하되 **최소 5곳, 최대 15곳**으로 구성해줘. 이 숫자는 대안 루트 개수가 아니라 한 루트 안의 방문 장소 수야. 시간·영업·이동 조건을 억지로 무시해 수를 채우지 말고, 현실적으로 5곳을 넣을 수 없으면 코스 생성 불가와 이유를 알려줘. |
| 기본 목표 | 가까운 장소를 풍부하게 넣고 우회·되돌아가는 이동을 줄여줘. |
| 도보 | 실제 도보 한 구간 **1.6km·30분 이내**, 하루 합계 **8km 이내**로 해줘. |
| 버스 | 도보 코스가 어려울 때만 확인해줘. 버스 탑승은 **60분 미만**이어야 하고, 승하차 정류장까지 걷는 거리와 전체 이동시간도 확인해줘. |
| 운영시간 | 방문 날짜 기준 휴무·브레이크타임·입장/주문 마감·예상 체류시간을 확인해 시간표 안에 실제로 들어가는지 계산해줘. |
| 테마 하루 코스 | **방문 5곳 이상·4시간 이상**을 기본으로 하고, 출발 후 최대 9시간 안에 **20시까지 종료**해줘. 위 방문 장소 수 상한인 15곳도 지켜줘. |
| 시작시간 | 30분 간격으로 검사하고, 운영시간·실제 이동·종료 조건을 통과해 코스를 만들 수 있는 시각만 표시해줘. |
| 동선 검증 | 실제 도보·대중교통 경로로 순서별 소요시간을 다시 계산하고, 각 장소 도착시각과 최종 도착시각이 조건에 맞는지 확인해줘. 실제 경로를 확인하지 못하면 확정 코스로 표시하지 마. |
| 식사·카페 | 장소 운영시간과 동선에 맞춰 넣어줘. 맞춤 코스에서는 사용자가 식사 장소와 시각을 선택할 수 있게 해줘. |
| 필수 장소 | 사용자가 지정한 필수 장소는 반드시 포함해줘. 조건상 방문할 수 없으면 조용히 제외하지 말고, 제외 사유와 영향을 알려줘. |

지역 전용 테마를 내가 확정하면 권역별 장소, 실제 이동 수단, 개방·영업시간, 식사·휴식, 시작·종료 지점을 맞춰 당일치기 코스를 만들어줘. 산책·해변 등 긴 도보가 가능한 테마도 실제 보행 경로와 거리·소요시간을 확인하고, 카페·식사·관람·쉼터를 자연스럽게 넣어줘. 같은 풍경만 계속 걷는 코스가 되지 않게 해줘. 테마의 출발·도착은 권역에 맞추고, 맞춤 코스의 기본 출발·도착은 내가 확정한 교통 거점으로 설정하되 사용자가 바꿀 수 있게 해줘. 날짜·시작시간·혼자 여행 조건 등 현행 추천 입력과 계획표 연결도 확인해줘.

홈에는 새 지역 카드를 실제로 표시하고 클릭하면 그 지역 소개 화면으로 열리게 해줘. 현재 홈의 큰 지역 그림과 한 줄 두 카드 구성, 지역 소개의 `추천 루트 / 여행지 / 여행 정보` 구조를 확인해 적용해줘. 여행지 목록·상세에서 카테고리, 사진의 실제/예시 구분, 방문 안내, 가격, 운영시간, 출처, 지도와 계획표 연결이 새 지역에서도 보이는지 확인해줘. 미리보기 상태라면 카드와 화면에 이를 정확히 표시해줘.

## 기존 장소 교체와 검증

기존 장소와 중복을 제거해줘. 300곳 한도 때문에 교체가 필요하면 **카카오맵 평점이 확인된 기존 음식점·시장 먹거리** 중 점수가 낮은 곳부터 교체해줘. 평점 없는 장소를 낮은 점수로 간주하지 마. 삭제 장소의 이름·점수·평가 수·교체 이유와 앱의 검색·지도·코스에 미치는 영향을 기록하고 원 조사 자료는 보존해줘. 다른 카테고리의 삭제나 평점 외의 기준이 필요해지면 먼저 물어봐줘.

자료 출처와 검증 결과를 지역 조사 문서에 남기고, 실제 앱의 홈·지역 소개·목록·상세·사진·지도·테마·맞춤 코스·계획표를 확인해줘. 가능한 범위에서 데스크톱·작은 화면, 데이터 검사, 빌드, 관련 회귀 검사를 실행해줘. 사용자에게 보이는 지역 카드가 빠지거나 경로 좌표가 없는 장소가 자동 추천에 들어가지 않는지도 확인해줘. 로컬 검증과 실제 영업·현장 이동·공개 사이트 검증을 구분해줘.

예약 안내는 여행지에서 바로 추가, 계획표의 검색·추천, 추천 코스의 개별 장소·전체 코스 가져오기, 보류 장소 적용 등 **계획표에 들어가는 모든 경로**에서 확인해줘. 예약 필수·권장·미확인과 특정 체험에만 적용되는 경우에 맞는 경고가 뜨는지, 취소하면 일정이 추가되지 않는지, 계속 넣어도 예약 완료로 표시되지 않는지 검증해줘.


완료 보고에는 조사한 권역과 검색 방법, 카카오맵 평점·평가 수를 **직접 확인한 장소 수**, 앱에 추가·삭제한 장소와 이유, 카테고리별·전체 장소 수, 운영·가격·사진·좌표가 미확인인 항목, 코스 및 화면 검증 결과, 남은 한계를 적어줘. 검색 결과 일부만 확인했다면 **전수 조사 완료**라고 말하지 마. 공개 배포를 하지 않았다면 로컬 적용과 공개 적용을 구분해줘. 실제 사용한 서브에이전트·Skill·이미지 생성·Git 작업은 계획한 도구와 구별해 작업기록에 남겨줘.
