# 나주 지역 내 교통: 나주역 ↔ 금성관

조사일: 2026-10-01. 목포↔나주 열차는 [지역 간 교통](../../지역간-교통.md)에 기록한다. 이 문서는 나주시 내 정류장과 시간표만 다룬다.

[나주시 BIS 노선검색](https://bis.naju.go.kr/busmap/lineSearch)의 순환1(`LINE_ID=8021`)·순환2(`LINE_ID=8022`) 정류장 목록과 [나주시 BIS 공지의 2025-10-13 시행 시간표](https://bis.naju.go.kr/guide/notice/noticeList) 85·87쪽을 대조했다. 공지 등록일은 2026-04-16이다. 금성관은 [나주시 관광 10선](https://www.naju.go.kr/www/administration/reporting/coverage?idx=95334&mode=view&page=3)에 포함된다.

| 이동 | 노선·정류장 | 공식 시간표 예시 |
| --- | --- | --- |
| 나주역 → 금성관 | 순환2 나주역 `188` [35.01443915, 126.71651246](https://www.openstreetmap.org/?mlat=35.01443915&mlon=126.71651246#map=18/35.01443915/126.71651246), 순서 59 → 금성관 `134` [35.03218839, 126.71653319](https://www.openstreetmap.org/?mlat=35.03218839&mlon=126.71653319#map=18/35.03218839/126.71653319), 순서 68 | 08:10→08:20, 09:50→10:00, 마지막 표기 19:00→19:10. 이 구간 표상 10분. |
| 금성관 → 나주역 | 순환1 금성관 `2193` [35.03209932, 126.71650305](https://www.openstreetmap.org/?mlat=35.03209932&mlon=126.71650305#map=18/35.03209932/126.71650305), 순서 7 → 나주역 `187` [35.01470134, 126.71637955](https://www.openstreetmap.org/?mlat=35.01470134&mlon=126.71637955#map=18/35.01470134/126.71637955), 순서 17 | 06:43→07:29, 17:03→17:49, 마지막 표기 18:43→19:29. 이 구간 표상 46분. |

**방향 주의:** 순환1·2는 같은 역과 관광지 이름이 목록에 여러 번 나와도 진행 방향이 다르다. 순환2의 역→금성관은 비교적 짧지만, 순환1의 금성관→역은 시청·영산포 방면을 돌아 표상 46분 걸린다. 이 시각은 PDF에 해당 지점별로 **명시된 시각**이며 개별 정류장 현장 시각이나 정시 운행 보증은 아니다.

나주시 [요금 안내](https://bis.naju.go.kr/useinfo/trafficFare?tabIndex=3)는 순환버스 일반 성인 요금을 1,000원으로 안내한다. 일반 관광객 무료 버스로 계산하지 않는다.

**미검증:** 나주역 승강장↔버스 정류장·금성관 정류장↔실제 입구 도보, 여행일의 운행·우회, 주말/휴일 별도 시각 적용 여부, 탑승 가능 잔여 자리. 나주의 다른 관광지로 확장할 때는 해당 지역 안에서 별도로 조사한다.
