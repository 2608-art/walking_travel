# 목포 권역 테마 루트 검증 기록

**확인일:** 2026-10-07 (한국 시간)
**검증 기준:** 코스당 방문지 5~15곳, 테마당 서로 구별되는 코스 5~15개(목표 10개). 지도 화면의 도보·대중교통 경로와 거리·시간을 구간별로 확인한 코스만 확정한다.

## 결과 요약

수정본 앱에서 여섯 테마 카드가 표시되는 것을 확인했다. `근대거리·시장` 카드를 눌러 날짜별 추천 루트 화면으로 진입했으나, 오늘(2026-10-07) 계산 결과 시작 시각 선택란에 `가능한 시작시간 없음`이 표시됐고 `하루 시간표 만들기`가 비활성화됐다. 안내는 5곳 이상 실제 이동 경로까지 확인한 시작시간이 없다고 표시했다. 검토용 계획표를 저장하지 않았으며, 생성된 테마 코스는 0개다.

현재 로컬 미리보기는 Worker/API 서버를 포함하지 않는 정적 파일 서버다. 시작시간 후보 계산 중 `GET /api/route?mode=walk&start_x=126.3859&start_y=34.7914&end_x=126.3820996&end_y=34.7879739&start_id=station&end_id=p2` 요청이 **404 File not found**로 반환됐다. 따라서 이는 외부 지도 서비스의 404 또는 사용자의 API 한도 응답을 직접 관측한 결과가 아니다. 사용자는 API 한도가 소진됐다고 알렸으며, 본 검증에서는 그 한도를 우회하는 API 호출을 사용하지 않았다.

## 카드 그림·진입 확인

여행지 소개의 추천 루트 카드에 여섯 권역 테마 이름과 설명이 표시됐다. 여섯 카드 모두 동일한 접힌 지도와 핀 그림을 사용한다. 그림은 특정 장소나 잘못된 이동 방법을 암시하지 않는 공통 루트 아이콘이어서 명백한 내용 불일치로 판정하지 않았다. `근대거리·시장` 카드 클릭은 추천 루트 화면으로 이동했다. 해당 화면에서 시작 가능 시간이 없어 이후 코스 생성은 막혔다. 나머지 다섯 카드의 개별 클릭 진입은 확인하지 않았다.

## 미확인 구간과 계속 진행 조건

- 여섯 테마 모두 방문 순서가 생성되지 않아 권역 안의 각 연속 구간, 마지막 장소에서 목포역으로 돌아오는 길, 버스 승하차 위치와 이동시간을 확인하지 못했다.
- 근대거리·시장 테마 시도에서 앱 경로 API의 로컬 endpoint가 404를 반환했다. 현재 작업 환경에서 Worker 경로 제공자가 구동되지 않은 것이 직접 원인이다. 사용자가 알린 외부 API 한도 소진도 별도 제약이다.
- 개별 장소의 정확한 출입구 주소가 없는 곳, 경사·횡단·골목 폐쇄, 당일 영업·휴무·날씨, 개인별 피로도와 만족 가능성은 확인되지 않았다.
- 실제 지도 경로가 필요한 구간은 공식 도보·대중교통 길찾기를 다시 확인한 뒤 기록한다. 앱에 계획표를 저장하더라도 그 사실만으로 구간 검증 완료로 취급하지 않는다.

**결론:** 이번 확인으로 확정한 테마 코스는 없다. 기존 역→인스파이어링 커피 단일 지도 구간만 참고 확인했다. 경로 백엔드가 준비되고 실제 지도 경로로 각 구간이 확인되기 전까지 테마별 코스 수를 충족했다고 말할 수 없다.

## 지도 경로 API 선택 참고

사용자가 Kakao API 한도 소진을 알려왔지만, 그 응답 자체를 재현하거나 앱 계정의 잔여량을 읽지는 않았다. Kakao 개발자 문서상 보행·대중교통 경로는 일일 1,000회 한도와 호출당 10원 추가요금 표기가 있으므로, 먼저 실제 계정의 API별 사용량을 확인하는 것이 맞다. 공개 Naver Cloud Directions 5/15는 문서상 자동차 경로 API이므로 이번 도보·대중교통 문제의 대체제가 아니다. Google Routes API는 WALK·TRANSIT 모드를 제공하지만, Google Maps 웹 화면에서 목포 보행 검색은 “서비스 검색 범위 밖”으로 표시됐다. API별 지역 적용 결과는 키 없이 검증하지 않았다. 따라서 Google은 소량 시험 후보일 뿐이며, 키는 서버 측 비밀로 제한하고 일일 예산·할당량을 설정한 뒤 목포의 WALK·TRANSIT 각각 1–2개 요청으로 지원 여부와 응답을 확인해야 한다. 이번 작업에서는 Cloud 결제·키 설정을 하지 않았다.

- Kakao 한도·요금: https://developers.kakao.com/docs/en/getting-started/quota
- Naver Directions 공식 문서: https://api.ncloud-docs.com/docs/ai-naver-mapsdirections-driving
- Google Routes 이동 모드: https://developers.google.com/maps/documentation/routes/route-opt
- Google Transit 경유지 제한: https://developers.google.com/maps/documentation/routes/transit-route
- Google 키 보안 권고: https://developers.google.com/maps/api-security-best-practices

**판정:** 남은 네 테마의 앱 자동 생성·저장·완전 경로 검증은 미완료다. 현재 엔진도 테마당 한 코스만 반환한다. 기존 두 검토계획과 이번에 확인한 구간 표본을 제외하고, 미확인 연결이 있는 경로를 확정 코스로 표시하지 않는다.

### 보행·운영 검토 판정

- 서산동을 스카이워크 시작에서 골목→보리마당→해안·유달유원지→스카이워크 순으로 수정했다. 역 주변에서 출발해 2개의 버스 연결로 총 길선 도보를 4.07km로 낮췄다. 기존 책방 시간 메모(11:00 시작)보다 이른 방문도 11:00 이후로 이동했다.
- 평화광장은 15:30 시작·버스 66번으로 카페에 접근하고, 광장 산책→저녁 1끼→20:00 분수 일정→간식으로 수정했다. 기존 늦은 점심과 저녁을 가까운 시간에 연속 배치한 점을 제거했다. 평화광장의 실제 행사 날짜·요일·기상 운영과 바다 쪽 관람 접근은 추가 확인 대상이다.
- 전체 테마의 일반 일정은 아침·점심·저녁 세 끼를 반영했고 비카페 테마 카페는 세 끼 장소 수 이하로 제한했다. 카페 테마는 8곳 모두 카페이며 음식점이 없다. 세부 메뉴·운영시간·휴무 충돌은 장소별 메모에 남겼다.
- 앱 계획 목록에는 기존 2개 계획을 보존하면서 새 `[검토용·미확정]` 테마 계획 6개를 추가했다. 저장 계획·GPX/GeoJSON·Google 대중교통 UI 후보 확인은 전 구간 독립 검증이나 현장 접근 확인과 다르다.

**미확인:** 모든 보행 leg의 Kakao/Naver/Google 화면별 실제 경로, 도보 입구, 정류장별 승하차, 대기시간, 계단·언덕·횡단·통제, 임시 휴무 및 공사. 이를 확인하기 전에는 어떤 코스도 확정 경로로 표시하지 않는다.

### 모든 테마 공통 방문 순서 기준과 삼학도 수정 (2026-10-07)

사용자는 모든 테마에서 장소명·콘텐츠 순서보다 실제 도보 동선을 우선하고, 직선거리만으로 연결을 판단하지 않으며, 가까운 다음 장소로 한 방향 진행해 이미 지난 권역으로 돌아가지 않도록 지정했다. 시내 대표 출발과 식사·카페의 동선 배치도 공통으로 적용한다. 사용자가 특정 순서를 지정하면 우선하며, 지도 UI·출입구를 확인하지 못한 구간은 미확인으로 남긴다. 이 원칙을 생성 스크립트의 공통 메타데이터와 앱 코스 상세에 추가했다. 기존 다섯 코스의 저장된 순서와 보행망 연결은 유지했다. 이들은 구간별 지도 UI 대조가 남아 있어 순서의 현장 검증을 완료한 것으로 표현하지 않는다.

삼학도는 기존 저장 순서가 지도 번호 5→6→7→8(기념관→과학관→이난영공원→항구포차)이었고, 사용자가 제시한 7→5→6→8과 다름을 확인했다. 아침·시장·공부방·점심 뒤에 **7 난영공원→5 평화기념관→6 바다과학관→8 항구포차**를 배치해 보행 경로를 다시 생성했다. 새 저장 보행망은 총 4.716km/62분, 방문 8곳, 버스 0회, 단일 연결 길선이며 예상 종료는 18:30이다. 변경으로 새로 생긴 p51→p26, p26→p30, p32→p53은 지도 UI 대조 미완료다. 그대로 유지한 p30→p32만 Naver 지도에서 398m/6분 확인된 이력이 남아 있다. 새 거리·순서는 보행망으로 계산한 검토 결과이며 확정 코스가 아니다.

### 평화광장 도보 선분 정정 (2026-10-07)

카카오맵 도보 UI에서 커피창고로(평화광장점)→평화광장 292m/5분, 평화광장→해빔 444m/7분을 확인했다. 기존 gpx.studio 결과는 같은 구간을 각각 1.20km와 1.14km로 우회했으므로 그 경로 형상을 삭제하고 [첫 구간](https://map.kakao.com/link/by/walk/%EC%BB%A4%ED%94%BC%EC%B0%BD%EA%B3%A0%EB%A1%9C,34.7956475,126.4306203/%ED%8F%89%ED%99%94%EA%B4%91%EC%9E%A5,34.7960696,126.4330925), [둘째 구간](https://map.kakao.com/link/by/walk/%ED%8F%89%ED%99%94%EA%B4%91%EC%9E%A5,34.7960696,126.4330925/%ED%95%B4%EB%B9%94,34.7946403,126.4300707)으로 확인 근거를 남겼다. 두 구간은 카카오 UI에서 경로를 확인했지만, 저장된 GPX/GeoJSON에는 형상을 싣지 않았고 지도에서도 선으로 그리지 않는다. 세 번째 해빔→88포장마차 524m/6분 선만 저장되어 있다. 코스 총 보행 합계는 확인 UI 거리와 저장 경로를 합한 1,260m/18분이며 실제 선 표시 길이는 524m다. 행사 핀과 버스 접근도 걷기 선에 연결하지 않았다. 검토 계획 6개를 새로 추가하는 대신 앱에서 같은 6개 계획을 갱신하도록 바꾸어 기존 사용자 계획 2개를 보존한다. 이 정정 후에도 나머지 모든 도보 구간을 UI로 대조한 것은 아니므로 6개 테마는 검토용·미확정 상태다.
