# 교통 조사: 목포와 인접 지역

조사일: 2026-10-01. 목포 안의 이동과 인접 지역 연결을 이 파일 하나에 모은다. 지역별 제목으로 구분하고 각 관광지·정류장의 실제 소재지를 명시한다. 렌터카·자가용은 제외한다. 택시는 기본 코스에서 제외하되, 사용자의 2026-10-01 요청에 따라 카카오 T 호출 가능성을 별도 검증 항목으로 기록한다.

## 목차

- 목포 안: 정류장, 버스, 여객선, 케이블카, 무료·유료 이동수단
- 목포 ↔ 인접 지역: 나주 철도, 무안·영암 버스
- 나주 안: 나주역 ↔ 금성관
- 무안·영암 안: 확인 범위와 미검증 항목
- 데이터 적합성 및 카카오 T 호출 가능성

## 확인 범위와 판정

- **확인**: [목포시 2026-09-01 공영버스 운행현황](https://m.mokpo.go.kr/www/life_welfare/traffic/city/operation_status)에 88, 88-1, 200, 210, 66-1번이 등재되어 있다. 2026-10-01 조회한 [목포시 ITS 노선 지도](https://its.mokpo.go.kr/its/bus3.view)에서도 해당 노선의 정류장 순서, 정류장 고유번호, 위도·경도가 조회된다. 따라서 과거 노선번호를 그대로 옮긴 상태는 아니다.
- **확인**: 아래 좌표는 ITS의 해당 노선 정류장 목록에 표시된 **정류장 위치**다. 지도 링크는 이 좌표를 핀으로 보여준다. 같은 이름의 길 건너 정류장은 고유번호와 좌표를 따로 적었다.
- **미검증**: 실제 관광지 입구에서 정류장까지의 보행 경로·거리, 횡단보도와 경사, 정류장별 버스 도착시각, 특정 날짜의 결행·우회 여부. 정류장 이름만으로 관광지 입구 바로 앞이라고 단정하지 않는다.
- **시간 주의**: 아래 첫차·막차는 버스 **기점 출발시각**이다. 해당 정류장에 도착하는 시각이나 관광지에서 탈 수 있는 마지막 버스 시각으로 사용하면 안 된다.
- **2026-10-01 재조회:** [목포시 공영버스 운행현황](https://m.mokpo.go.kr/www/life_welfare/traffic/city/operation_status)은 여전히 **2026-09-01 기준**이며, 이 문서의 1·22·22-1·22-2·33·66-1·88·88-1·200·210·300·300A·500·900·900A·올타2001번이 목록에 있다. 이는 정기 노선의 등재 확인이지 조회 순간 모든 차량의 운행이나 특정 여행일의 막차 보증이 아니다. [시내버스 공지 목록](https://car.mokpo.go.kr/www/life_welfare/traffic/city/notice)의 최신 게시글은 2026-09-03 등록된 아트페스티벌 우회이며, 본문상 **2026-09-19~20**의 88-1·22-1·33번 한시 우회였다. 지난 행사 공지를 10월 상시 우회로 적용하지 않는다.
- **당일 변경과 자동 갱신:** 정기 시간표에 표시된 구간 단축은 계획된 편성이지만, 행사·공사·사고·날씨로 달라지는 운행은 해당 날짜의 공지·실시간 정보가 필요하다. 하루 한 번 정적 PDF를 내려받아도 당일 변경을 빠짐없이 반영할 수 없다. [목포시 공식 설명](https://www.mokpo.go.kr/www/mokpo_news/press_release/report_material?idx=543316&mode=view)은 교통정보센터에서 실시간 버스 위치·정류장 정보를 보여준다고 하지만 공개 화면 제공과 앱용 데이터 제공 권한은 다르다. [국토교통부 TAGO 버스도착 API](https://www.data.go.kr/data/15098530/openapi.do)는 실시간 서비스이나 **목포 지원 도시코드와 이 문서의 정류장에 대한 실제 응답은 검증하지 않았다.** 따라서 앱의 목포 버스 자동 동기화 가능성도 아직 확정하지 않는다.

### 코스 계산에 바로 영향을 주는 점

- 88번과 88-1번 정류장 목록에는 **목포역 정류장이 없다**. 목포역에서 이 노선을 바로 탄다는 코스는 만들 수 없다. 원도심의 실제 환승 또는 도보 연결을 검증해야 한다.
- 88번은 `근대역사관 → 자연사박물관` 순서지만 17번에서 54번까지 긴 순환이다. 반대편 88-1번은 `국립해양유물전시관 → 근대역사관` 순서지만 7번에서 42번까지 긴 순환이다. 둘 다 실제 시간 측정 없이 관광지 사이의 간편한 직행편으로 간주하지 않는다.
- 210번은 목포역과 평화광장 입구를 양방향으로 잇는 정류장 순서가 확인된다. **편도 소요시간 및 각 정류장 막차는 확인되지 않았다.**
- 66-1번은 목포역과 북항회어시장을 지나지만, 시 [현재 노선도](https://m.mokpo.go.kr/contents/28779/260518/66-1.jpg)에 북항 케이블카 승강장 경유가 없다. **2026-10-01 추가 조사에서 1번이 목포역과 `목포해상케이블카` 정류장을 경유함을 확인했다.** 아래 추가 조사 항목을 우선 적용한다.

## 미검증 목록과 다음 검증 단계

1. 관광지 **실제 입구 좌표**와 위 정류장 사이의 도보 경로·시간. 현재 지도 링크는 정류장 핀 확인용이다.
2. 88·88-1·210·66-1번의 **각 정류장 실제 통과시각과 그 정류장에서의 마지막 탑승 가능 시각**. 공개 시간표의 기점 시각을 그대로 더해 계산하지 않는다.
3. 210번 평화광장 → 목포역 실제 소요시간과 **귀가 열차 연계 가능 여부**. 210번은 170~200분 배차이므로 놓쳤을 때의 대안도 필요하다.
4. 목포역 ↔ 근대역사관·유달산권 도보 또는 다른 버스 환승, 갓바위 박물관권 ↔ 평화광장의 검증된 동선. 목포역 ↔ 케이블카 북항승강장은 **1번 노선 연결 확인**, 정류장별 시각·승강장 입구 보행은 미검증.
5. 조사 당일 ITS에 등록된 노선의 **특정 여행일 결행·공사 우회·임시 변경**은 확인되지 않았다. 여행일을 정하면 직전에 실시간 조회가 필요하다.

### 범위와 다음 검증

- 위는 **존재·방향·일부 시간표가 검증된 연결편**이다. 무안·영암의 하루 관광 가능 여부까지 검증한 것은 아니다.
- 목포와 인접 지역의 다른 버스·철도·여객선 연결을 모두 조사 완료했다고 보지 않는다. 특히 신안 연결과 추가 무안·영암 노선은 별도 조사 대상이다.
- 여행일과 방문 관광지를 정하면 각 정류장의 마지막 승차시각, 실제 도보 이동, 귀가 열차·배편을 양방향으로 다시 조회한다.

[나주시 BIS 노선검색](https://bis.naju.go.kr/busmap/lineSearch)의 순환1(`LINE_ID=8021`)·순환2(`LINE_ID=8022`) 정류장 목록과 [나주시 BIS 공지의 2025-10-13 시행 시간표](https://bis.naju.go.kr/guide/notice/noticeList) 85·87쪽을 대조했다. 공지 등록일은 2026-04-16이다. 금성관은 [나주시 관광 10선](https://www.naju.go.kr/www/administration/reporting/coverage?idx=95334&mode=view&page=3)에 포함된다.

**방향 주의:** 순환1·2는 같은 역과 관광지 이름이 목록에 여러 번 나와도 진행 방향이 다르다. 순환2의 역→금성관은 비교적 짧지만, 순환1의 금성관→역은 시청·영산포 방면을 돌아 표상 46분 걸린다. 이 시각은 PDF에 해당 지점별로 **명시된 시각**이며 개별 정류장 현장 시각이나 정시 운행 보증은 아니다.

나주시 [요금 안내](https://bis.naju.go.kr/useinfo/trafficFare?tabIndex=3)는 순환버스 일반 성인 요금을 1,000원으로 안내한다. 일반 관광객 무료 버스로 계산하지 않는다.

**미검증:** 나주역 승강장↔버스 정류장·금성관 정류장↔실제 입구 도보, 여행일의 운행·우회, 주말/휴일 별도 시각 적용 여부, 탑승 가능 잔여 자리. 나주의 다른 관광지로 확장할 때는 해당 지역 안에서 별도로 조사한다.

## 무안 지역 내 교통

조사일: 2026-10-01. 목포↔무안 200번의 승하차 정류장과 기점 시간표는 위 목포 ↔ 무안 구역에 기록했다. 무안군청 정류장에서 실제 관광지까지 이동할 수 있는지, 무안 지역 내부의 버스·도보 연결은 아직 검증하지 않았다. 해당 관광지를 정할 때 장소 주소·입구, 정류장별 승하차 시각과 귀환편을 이 구역에 기록한다.

## 영암 지역 내 교통

조사일: 2026-10-01. 목포와 경계를 넘는 300·300A·500번의 정류장 방향과 위치는 위 목포 ↔ 영암 구역에 기록했다. 영암군 내 관광지 입구와 지역 내 이동은 아직 검증하지 않았다.

현재 확인된 영암 쪽 후보 정류장은 삼호농협, 구.삼호터미널, 농업박물관, 독천터미널이다. **정류장 명칭만으로 관광지까지 걸어갈 수 있는지, 다음 버스나 목포 귀환편을 탈 수 있는지는 판단하지 않는다.** 나중에 영암 코스를 구성할 때 관광지 실제 주소·입구, 정류장까지 보행, 정류장별 첫차·막차를 이 구역에 기록한다.

## 버스 코스 판정과 GTFS 문장 검토

검토일: 2026-10-01. 사용자 제시 문장: “버스를 타는 코스는 정류장별 운행 시각이 부족해 현재 자료만으로 가능하다고 확정할 수 없습니다. GTFS 기준처럼 편별 정류장 시각과 운행일이 필요합니다.”

**판정: 현재 목포 버스 자료에 대한 결론은 대체로 맞다.** [GTFS Schedule 공식 참조](https://gtfs.org/documentation/schedule/reference/)는 `trips.txt`로 운행편, `stop_times.txt`로 편별 정류장 도착·출발시각, `calendar.txt`/`calendar_dates.txt`로 운행일과 예외를 표현한다. 현재 확보한 목포시 PDF는 상당수가 **기점 시각**, ITS는 **노선·정류장 순서** 중심이어서 임의의 시작 시각에 버스 대기·환승·귀환을 계산해 “가능”이라고 확정하기에 부족하다. 다만 22-1·22-2번의 고하도 승강장이나 나주 순환버스처럼 일부 구간은 공식 표에 중간 지점 시각이 있다.

**표현상 주의:** GTFS 파일 형식 자체가 필수인 것은 아니다. 같은 수준의 검증 가능한 편별 승하차 시각·운행일·예외 정보가 다른 공식 데이터/API로 제공되어도 된다. GTFS도 추정 시각(`timepoint=0`)을 허용하고, 정적 시간표는 당일 지연·결행을 보장하지 않는다. 따라서 앱에서는 `노선 존재 확인`과 `시간표상 코스 가능`, `당일 운행 확인`을 서로 다른 판정으로 둔다. 정류장별 시각이 없는 구간은 `시간 확인 필요`로 둔다.

## 첫 원도심 도보 코스: 이동 구간 검증용 초안

[장소.md](장소.md)의 첫 추천 코스 초안 **목포역 광장 → 노적봉 → 근대역사관 1관 → 2관 → 목포역 광장**에 쓰는 네 구간만 계산했다. 2026-10-01에 [OpenStreetMap 보행 경로 엔진](https://routing.openstreetmap.de/routed-foot/route/v1/driving/126.3860552,34.7911625;126.3820996,34.7879739;126.3820943332,34.7875870369;126.3814912,34.78596374;126.3860552,34.7911625?overview=false)으로 **지도 핀 사이** 경로를 조회했다. 출발·귀착점은 역 현관이 아닌 **목포역 광장 남쪽 정류장 인근**(34.7911625, 126.3860552)이다. 라우터가 시설 핀을 보행로로 스냅하므로 아래 숫자는 현관 간 실측 시간이 아니다.

| 도보 구간 | 보행 경로 엔진 결과 | 코스 계산 판정 |
| --- | --- | --- |
| 목포역 광장 남측 기준점 → 노적봉 핀 | 약 738m, 10분 | 역 실제 출입문과 노적봉 보행 진입로 미확인. 계단·횡단·경사 여유 별도 |
| 노적봉 핀 → 1관 핀 | 약 39m, 1분 미만 | 바위에서 실제 내려오는 길과 1관 현관 방향 미확인. **1분 이동 확정 금지** |
| 1관 핀 → 2관 핀 | 약 267m, 4분 | 각 관 출입문 좌표 미확인. 관람 종료 후 퇴장·건너기 여유 별도 |
| 2관 핀 → 목포역 광장 남측 기준점 | 약 843m, 11분 | 2관 출입문과 역 현관·플랫폼 이동 미포함 |

핀 간 보행 합계는 **약 1.9km·25분**이다. 정확한 입구를 확인하기 전에는 코스에 이 값을 그대로 넣지 않고 **구간별 추가 여유**를 둔다. 특히 노적봉↔1관의 1분 미만 결과는 현장 진입로를 확인할 때까지 미확정이다. 첫 초안에는 버스·환승·여객선이 없으므로 기존 정류장별 시각 및 새 섬 항차의 미확정성이 이 코스의 이동 계산에는 개입하지 않는다. 철도로 목포역에 도착·출발한다면 열차 시각과 플랫폼↔광장 이동은 여행 날짜가 정해진 뒤 별도로 더한다.
