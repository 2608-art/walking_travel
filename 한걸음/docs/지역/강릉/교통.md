# 강릉 교통 조사

조사일: 2026-10-01. 이 문서는 강릉의 교통 조사 원본이다. 첫 범위는 **강릉역·시내 ↔ 안목·강문·경포**이며, 오죽헌·선교장은 연결 후보로 확인했다. 렌터카·자가용·택시는 기본 코스에서 제외한다. 여행 날짜와 출발 시각은 아직 정하지 않았다.

## 판정과 자료 읽는 법

- **노선·방향 확인:** 강릉시 [버스정보시스템 노선 검색](https://bis.gn.go.kr/search?type=route)의 노선 목록과 상세 정류장 순서·정류장 ID·좌표를 2026-10-01 조회했다. 현재 목록의 `0대 운행중`은 조회 순간의 차량 수이며, 노선 폐지를 뜻하지 않는다. 다만 `(운행 중단)`·`(운행 폐지)`로 명시된 노선은 후보에서 제외한다.
- **시간 확인 수준:** [배차시간표](https://bis.gn.go.kr/schedule)에는 평일·방학·토요일·일요일/공휴일 선택과 운수사별 기점 첫차·막차가 있다. 노선 상세의 `routeTime.avgTime`에는 정류장별 표시 시각이 있지만, 이번 조사에서 **각 시각의 편 식별자·운행일·변경 적용일**을 확인하지 못했다. 아래 정류장 시각은 **조회일 표시값**으로만 기록하며, 서로 다른 정류장의 시각을 임의로 한 편으로 연결하지 않는다.
- **단축 운행 구분:** 배차표에 미리 적힌 `미경유`·회차 편은 계획된 편성이다. 사고·날씨·행사로 당일 바뀌는 결행·우회·단축과 구별한다. [BIS 관리자 설명](https://bis.gn.go.kr/qna/view?qnaSeq=1500)에 따르면 배차표는 기점 출발 시각이고 정류장 도착 예정은 차량 출발 후 단말기 위치 정보로 계산된다. [단말기 오류 사례](https://bis.gn.go.kr/qna/view?qnaSeq=2110)도 있어 실시간 화면에 안 보인다는 사실만으로 결행을 확정할 수 없다. 하루 한 번 정적 시간표를 가져오는 방식으로 당일 변경을 보장할 수 없다.
- **자동 갱신 가능성:** 강릉시 [ITS 공개 API 목록](https://its.gn.go.kr/information/openApi)에는 확인한 범위에서 버스 배차표·실시간 위치 API가 없었다. [BIS API 문의 답변](https://bis.gn.go.kr/qna/write?mode=R&qnaSeq=1139)도 담당 부서 문의를 안내할 뿐 공개 이용 조건을 확인해 주지 않는다. 따라서 공식적으로 사용할 수 있는 버스 데이터 피드·갱신 주기·사용 허가를 확인하기 전에는 앱이 매일 자동 반영할 수 있다고 단정하지 않는다. 계획 편성은 기준일을 붙여 저장하고, 비정기 변경은 당일 공지·실시간 조회를 별도로 확인해야 한다.
- **코스 가능 판정:** 아래 연결은 노선과 방향의 후보이다. 특정 날짜·시각의 승차, 환승, 관광지 입구까지의 보행, 마지막 귀환을 하나의 여정으로 검증하지 못했으므로 아직 `시간표상 가능` 코스가 아니다. 실제 여행일에는 [공지](https://bis.gn.go.kr/board/notice/list)와 실시간 도착정보를 다시 확인한다.
- **지도:** 아래 좌표는 **정류장 핀**이며 관광지 출입구나 역 출입문 위치가 아니다. 지도 링크도 정류장 핀 확인용이다. 보행시간은 아직 산출하지 않았다.

## 요금·특수 이동수단·변경 공지

- [강릉시 BIS 요금 안내](https://bis.gn.go.kr/info): 일반 시내버스 성인 카드 **1,530원**, 현금 **1,700원**(조회일 게시값). 교통카드 하차 태그 후 1시간 이내 2회 무료환승이며 **동일 번호 재탑승은 제외**한다. 이것은 무료 버스가 아니라 환승 할인이다. 시티1번도 [BIS 관리자 답변](https://bis.gn.go.kr/qna/view?qnaSeq=1594)에 따르면 일반 시내버스와 같은 방식으로 정차하고 같은 요금을 받는다.
- 시티·마실버스는 행사 때 운행이 달라질 수 있다. [2026-09-29 공지](https://bis.gn.go.kr/board/notice/view?noticeSeq=772)는 **2026-10-10 경포마라톤** 때문에 일부 시티·마실버스 결행·단축을 예고했다. 공개 웹 본문에서 영향받는 편 목록은 확인되지 않았으므로 해당 날짜의 코스에 시티1을 고정 사용하지 않는다.
- 정동진은 첫 범위 밖이다. [113번 우회 공지](https://bis.gn.go.kr/board/notice/view?noticeSeq=754)는 공사로 2026년 10월 말 예정까지 우회와 임시 승하차 장소를 알린다. 정동진 확장 시 최신 공지를 다시 확인한다.
- **초기 조사 기록:** 관광형 자율주행차·무료 셔틀·철도 및 인접 도시 연결은 당시 현행 운행일·정류장·시각을 검증하지 않았다. 2026-10-01 재검토에서 아래 자율주행차·시티콜버스·철도 자료를 추가 확인했다. 여행일별 탑승 가능 여부는 여전히 별도 확인이 필요하다.

## 2026-10-01 재검토: 기존 내용의 사실성

- 기존 202·202-1·223·223-1·시티1의 **노선 번호, 주요 정류장 방향, 정류장 ID·좌표**를 [강릉시 BIS 노선 상세](https://bis.gn.go.kr/search?type=route)와 다시 대조했다. 확인한 항목에서 정반대 방향으로 적거나 폐지 노선을 운행 노선으로 적은 오류는 발견하지 못했다. 이것이 모든 편의 운행 확인을 뜻하지는 않는다.
- 기존 표의 첫차·막차는 대체로 **기점 출발 시각**이고, `routeTime.avgTime`은 정류장별 BIS **참고 표시값**이다. 편 번호·운행일과 연결되지 않아 `강릉역 21:53` 같은 값을 특정 목적지까지 가는 막차로 읽으면 틀릴 수 있다. 기존 문서의 미검증 판정을 유지한다.
- **심야버스가 없다는 BIS 관리자 답변**은 일반 버스에 관한 것이다. 강릉시는 [심야 자율주행 DRT 사업](https://www.gn.go.kr/www/selectBbsNttView.do?bbsNo=1630&key=6852&nttNo=203874)을 2026년 7월~2027년 6월, 22:00~05:00 운영 계획으로 발표했지만, 2026-09-03 [BIS 질의·답변](https://bis.gn.go.kr/qna/view?qnaSeq=2073)은 실제 개시를 확인해 주지 않았다. **심야 귀환 수단으로 확정하지 않는다.**

1. 버스는 평일/방학/주말/공휴일별로 **같은 편의 정류장 승하차 시각**, 단축·회차 여부, 각 방향의 마지막 승차 가능 편을 확인한다. 필요하면 강릉시 BIS 버스정보도우미 **033-660-2018**에 문의한다.
2. 자율주행차는 공개 리플릿의 적용일, 각 방향 정류장 위치, 당일 예약 가능 여부를 확인한다. 시티콜버스는 리플릿의 지점명보다 정밀한 승차 핀, 시범운행 종료 후 요금, 호출 가능 범위와 배차 조건을 확인한다.
3. 강릉역·정동진역·터미널의 출입구와 승차 위치, 주변 관광지 진입점 사이의 보행 경로·횡단보도·경사를 지도에서 확인한다.
4. 현행 확인이 안 된 케이블카·관광 체험 수단은 운영사 공지와 실제 탑승 조건이 확보될 때 상태를 갱신한다. 여객선은 일일 운항정보를 여행일에 다시 대조한다.

**현재 결론(2026-10-01 재검토):** 기존 핵심 버스 노선·정류장 방향에서 확인된 사실 오류는 없었지만, 무료 자율주행차와 시티콜버스가 빠져 있었다. 이들을 추가했고 A노선의 공개 시각표 방향도 분리해 적었다. 시티콜버스의 리플릿상 무료·승차 지점명, 강릉↔정동진 공식 편별 시각, 강릉–울릉 여객선의 2026-10-01 비운 상태까지 확인했다. **정류장별 버스 시각의 편·운행일, 공식 버스 자동 갱신 피드, 자율주행차 예약 가능 여부, 실제 출입구·정확한 승차 핀은 여전히 미검증이다.** 이 문서는 교통편 조사 기록이며 관광 코스 구성은 별도 요청이 있을 때 수행한다.
