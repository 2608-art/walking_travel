# 사진 출처와 이용 조건

사진은 장소·경로 데이터와 분리된 시각 자산이다. 촬영일의 모습이며 현재 운영이나 출입구를 보증하지 않는다. 사진 자체는 수정하지 않았고 Wikimedia의 1280px 제공본을 내려받았다. 화면 비율에 따라 CSS object-fit으로 일부 영역을 보여준다.

| 파일 | 촬영 대상·촬영자 | 출처·라이선스 | 적용 |
|---|---|---|---|

| yudalsan-panorama.jpg | 유달산, Matt872000, 2018-04-15 | [원본 설명](https://commons.wikimedia.org/wiki/File:Yudalsan_20180415_171946.jpg), [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) | 장소 p1 |

그 외 장소의 사진은 미등록이다. 다른 장소 사진으로 대신 표시하지 않는다. 홈페이지의 사진 출처 링크에서 이 문서를 열 수 있다.
